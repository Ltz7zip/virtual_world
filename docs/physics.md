# 物理模型文档

完整物理公式与方程见 `doc/方案/Python虚拟3D世界生成器：完整设计方案.md` 及
`doc/方案/气候系统模拟：严谨物理模型、动力学方程与加速方案/` 各篇。

## 因果链

```
行星参数 → 辐射强迫 → 地表能量 → 大气动力学 → 风应力 → 洋流
    ↓                                              ↓
    地形生成 → 气候场 → 降水 → 生物群系 → 土壤 → 农业
```

## 已实现（core 层）

| 模型 | 模块 | 说明 |
|------|------|------|
| 球面几何 | `core/spherical.py` | 坐标 / 面积 / 梯度、散度、涡度 / 科里奥利、β |
| 热平衡 | `core/planet.py` | `S0/4`、反演质量、大气气体常数、椭球半径 |
| 双线性/最近邻插值 | `core/interpolation.py` | 经度循环、纬度外推的数组级重采样 |

## 规划模块（随阶段实现）

| 阶段 | 物理模型 |
|------|---------|
| 地形 | 欧拉极点板块运动、Airy 均衡、管道水力侵蚀、休止角热力侵蚀、D8 汇流 |
| 辐射 | 开普勒方程、二流近似 / Delta-Eddington、宽带发射率、云/气溶胶光学 |
| 地表 | 能量平衡 `R_net = H + LE + G`、土壤热传导、海洋混合层、雪冰 |
| 大气 | 球面浅水 / 原始方程、谱方法、半隐式时间积分 |
| 海洋 | Sverdrup 平衡、Stommel-Munk 西边界层、Ekman、两箱热盐环流 |
| 降水 | CAPE 对流、上坡地形降水、大尺度层云、季风、再蒸发 |
| 分类 | Köppen-Geiger、Holdridge 生物群系、WRB 土壤、FAO AEZ 农业 |

守恒律（能量 / 质量 / 角动量 / 位涡 / 水量）的离散保留方式见 §5.2 方案文档。
