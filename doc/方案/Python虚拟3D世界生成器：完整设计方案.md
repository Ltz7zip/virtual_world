# Python 虚拟3D世界生成器：完整设计方案

## 一、总体架构

系统的核心设计理念是**数据驱动的分层生成管线**：以种子为起点，按物理因果顺序依次生成地形→气候→生态→农业，每一层的输出作为下一层的输入。所有模块共享同一个经纬度网格数据模型，确保不同图层之间可以精确对齐和交叉分析。

整个系统分为四个阶段：

**阶段一：行星基底生成**——确定行星半径、自转速率、轴倾角、恒星辐射强度、公转周期等基本参数。这些参数决定了后续所有气候过程的边界条件。例如自转速率影响科里奥利力强度，进而决定气压带风带的位置和强度；轴倾角决定季节差异的程度。

**阶段二：地形与海洋生成**——生成海拔网格、海洋掩码、海底地形。这是气候模拟的底层几何框架。

**阶段三：气候系统模拟**——依次计算温度场、气压场、风场、洋流场、降水场，最终进行气候分类。

**阶段四：地表系统输出**——生成农业类型图、等降水量图、气候分布图，并进行3D可视化渲染。


## 二、数据模型

### 2.1 核心网格结构

整个系统以一个**等经纬度网格**为基础数据结构，建议分辨率可配置（如 1°×1° 约 360×180，或 0.5°×0.5° 约 720×360）。每个网格单元存储一个**状态向量**：

```
cell = {
    # 地形层
    elevation:       float,    # 海拔高度 (m)，海洋为负值
    is_ocean:        bool,
    ocean_depth:     float,    # 海洋深度 (m)
    terrain_type:    enum,     # 平原/丘陵/山地/海底等

    # 温度层
    temp_jan:        float,    # 一月平均气温 (℃)
    temp_jul:        float,    # 七月平均气温 (℃)
    temp_annual:     float,    # 年均气温

    # 气压与风场
    pressure_jan:    float,    # 一月海平面气压 (hPa)
    pressure_jul:    float,    # 七月海平面气压
    wind_u_jan:      float,    # 一月纬向风分量
    wind_v_jan:      float,    # 一月经向风分量
    wind_u_jul:      float,
    wind_v_jul:      float,

    # 洋流
    current_u:       float,    # 洋流纬向分量
    current_v:       float,    # 洋流经向分量
    current_temp:    float,    # 洋流水温

    # 降水
    precip_annual:   float,    # 年降水量 (mm)
    precip_jan:      float,
    precip_jul:      float,
    precip_seasonality: float, # 降水季节性指数

    # 派生分类
    climate_class:   str,      # Köppen 气候代码 (如 Cfa, BWh)
    biome:           str,      # 生物群系类型
    soil_type:       str,      # 土壤类型
    agriculture:     str,      # 农业类型
}
```

这样的设计使任意图层都可以通过网格索引互相查询，比如“查看某地气候类型对应的土壤和降水”只需访问同一个 cell。地图渲染时，取任意字段即可生成对应专题图。

### 2.2 坐标系约定

纬度为 -90°（南极）到 +90°（北极），经度为 -180° 到 +180°。经度方向使用循环边界（环绕），纬度方向使用极点约束。这一点在计算风的纬向梯度和洋流环流时尤为重要。


## 三、生成管线详解

### 3.1 阶段一：行星参数定义

在生成地形之前，需要先定义行星的物理参数。这些参数直接决定后续气候模拟的方程形式：

```python
@dataclass
class PlanetParams:
    radius: float          # 行星半径 (m)，默认 6.371e6
    rotation_rate: float   # 自转速率 (rad/s)，默认 7.292e-5
    axial_tilt: float      # 轴倾角 (°)，默认 23.44
    solar_constant: float  # 恒星常数 (W/m²)，默认 1361
    orbital_period: float  # 公转周期 (天)，默认 365.25
    day_length: float      # 自转周期 (小时)，默认 24
    greenhouse_factor: float  # 温室效应因子，默认 1.0
```

改变这些参数会生成完全不同的世界。比如自转速率加倍会产生更强的科里奥利力，使气压带更加密集；轴倾角增大则季节差异更加极端。这种参数化设计让系统不仅生成“类地行星”，也可以生成各种理论上的宜居世界。


### 3.2 阶段二：地形生成

#### 方法选择

有两种主要的技术路线：

**路线A：板块构造模拟（推荐用于高物理真实性）**

基于 Voronoi 图将球面划分为若干板块，模拟板块的漂移、碰撞、俯冲过程，在碰撞边界产生山脉，在张裂边界产生海岭，在俯冲带产生海沟。mapwright 库提供了 Voronoi 地形生成、水力侵蚀、河流和生物群系的完整管线，纯 Python + NumPy 实现，完全种子确定性。FreezeDriedMangos 的 realistic-planet-generation-and-simulation 项目也实现了基于板块构造的地形生成，并进一步模拟了天气、气候和洋流。

**路线B：扩散模型生成（推荐用于高视觉质量）**

Terrain Diffusion 是 SIGGRAPH 2026 的工作，提供了 Perlin 噪声的深度学习的替代方案，支持无限、确定性的实时地形生成，提供 30m/px 和 90m/px 两种分辨率的预训练模型。先用粗分辨率（如 23km）生成宏观大陆轮廓，再用模型精修到高分辨率。这种方法的地形视觉质量显著优于纯噪声方法。

**混合方案**：用板块构造模拟生成宏观大陆格局（决定海陆分布和山脉走向），再用扩散模型或分形噪声精修局部地形细节。这样既有物理合理性，又有视觉丰富度。

#### 关键输出

- **海拔网格**：float 数组，海洋为负值
- **海洋掩码**：布尔数组
- **海底地形**：洋中脊、海沟、大陆架等
- **河流网络**：从降水数据反推（后文详述）


### 3.3 阶段三：气候系统模拟

这是整个系统中最复杂的部分。建议采用**简化物理模型 + 诊断式计算**的混合策略：对于需要时间积分的过程（如洋流），使用简化动力学方程做稳态求解；对于温度、气压等可以快速估计的量，使用诊断式物理关系直接计算。

#### 3.3.1 温度场

温度是最基础的气候变量。采用以下分解式：

**T(lat, lon, month) = T_base(lat, month) + ΔT_elevation + ΔT_continentality + ΔT_ocean_current + ΔT_perturbation**

各项含义：

- **T_base**：纬度基准温度，由太阳辐射的纬向分布决定。一月和七月分别计算，考虑行星轴倾角导致的太阳直射点移动。可以用一个简单的辐射平衡模型：
  
  `T_base = T_eq - (T_eq - T_pole) × sin²(lat) × f(month, axial_tilt)`

- **ΔT_elevation**：海拔递减率，标准值为 -6.5°C/km。oikoumene 项目在生成地球系统数据时也采用了相同的海拔递减率方法。

- **ΔT_continentality**：大陆性效应。远离海洋的内陆地区温度年较差更大，一月更冷、七月更热。可以用到最近海岸线的距离的指数衰减函数建模。

- **ΔT_ocean_current**：洋流对沿岸温度的影响。暖流经过的沿岸地区温度偏高，寒流经过的偏低。这需要先完成洋流模拟（见3.3.3）。

- **ΔT_perturbation**：地形扰动项，基于分形噪声生成，模拟局地气候差异。

#### 3.3.2 气压场与风带

气压场的计算基于**热力环流原理**：温度高的地区空气上升形成低压，温度低的地区空气下沉形成高压。

**气压场计算步骤**：

1. **纬向气压带**：根据行星自转速率和太阳辐射分布，确定行星风系的基本结构。对于类地行星，标准配置为：
   - 赤道低压带（0°附近，热力成因）
   - 副热带高压带（30°附近，动力成因）
   - 副极地低压带（60°附近，动力成因）
   - 极地高压带（90°附近，热力成因）

   自转速率会影响这些带的位置：自转越快，环流越复杂，气压带可能分裂为多个中心。可以用一个简化的参数化公式来确定各带的位置和强度。

2. **海陆热力差异**：陆地比热容小，升温和降温都快。夏季陆地形成热低压，冬季形成冷高压。这导致了季节性气压中心的变化（如亚洲高压/低压）。

3. **地形修正**：高原地形会改变局地气压分布，高原上气压整体偏低。需要用静力学方程从地形场推算气压修正。

**风场计算**：

风是气压梯度的结果，受到科里奥利力、摩擦力和地形的影响：

- **地转风**（自由大气）：`V_g = (1/ρf) × k × ∇p`，其中 f 是科里奥利参数，`f = 2Ω·sin(φ)`。puffins 库提供了科里奥利参数的直接计算函数，支持不同行星参数。

- **近地面风**：考虑摩擦力后风向与等压线成一定角度（通常海面上约15°-20°，陆地上约30°-45°）。风从高压吹向低压，北半球向右偏转，南半球向左偏转。

- **地形阻挡**：在山区，风场需要绕行或翻越山脉，产生背风坡的焚风效应。可以用简单的“风影”模型来处理。

#### 3.3.3 洋流模拟

洋流是虚拟世界气候模拟中最关键也最容易被忽视的模块。洋流将赤道的热量输送到高纬度，深刻影响沿岸气候。

**简化洋流模型**：

建议采用**风驱环流 + 热盐环流**的混合简化方案：

1. **风驱表层洋流**：主要由行星风带驱动。信风驱动赤道洋流向西流，西风驱动中纬度洋流向东流。在海洋盆地中，这些流动形成闭合的环流（gyre）。北半球形成顺时针环流，南半球形成逆时针环流。

2. **西边界强化**：由于科里奥利力随纬度变化（β效应），大洋西侧的洋流比东侧更强、更窄。可以用 Stommel 的β平面模型来计算。这解释了为什么地球上的湾流、黑潮等西边界流如此强劲。

3. **热盐环流**：高纬度海水冷却下沉，在深层向赤道流动，是温盐环流的简化形式。可以在模型中作为背景环流叠加。

4. **地形影响**：洋流在遇到大陆或海岭时会改变方向。FreezeDriedMangos 的项目实现了动态洋流模拟，并特别强调了洋流环流（ocean gyres）的模拟。

**洋流对气候的反馈**：

洋流模拟完成后，回到温度场计算步骤，用洋流数据修正沿岸温度。寒流经过的沿岸（如南美西海岸的秘鲁寒流）产生降温降湿效应，导致沿海沙漠；暖流经过的沿岸（如西欧的北大西洋暖流）产生增温增湿效应，使高纬度地区也变得温和湿润。

#### 3.3.4 降水场

降水是气候系统中最复杂的变量之一。采用**多机制分解**的方法：

**P = P_ITCZ + P_orographic + P_convective + P_frontal - P_evaporation_loss**

各分量：

- **P_ITCZ（赤道辐合带降水）**：赤道低压带上升气流产生强对流降水，全年丰富。这个分量在赤道附近最强，向两侧递减。

- **P_orographic（地形雨）**：湿润气流遇到山脉被迫抬升，冷却凝结产生降水。迎风坡降水丰富，背风坡干燥（雨影效应）。计算时需要沿主导风向追踪气流路径，累积水汽含量，在山脉迎风侧释放降水。TerraForge 库的多噪声地形生成支持基于海拔、湿度和温度地图的生物群系生成，其中湿度计算就考虑了地形雨的效应。

- **P_convective（对流雨）**：局地加热导致的强对流降水，在热带和夏季大陆内部最为常见。可以用温度场的空间梯度来参数化。

- **P_frontal（锋面雨）**：冷暖空气交汇产生的降水。在温带地区，气旋活动频繁，锋面降水是主要来源。可以用温度梯度的强度来参数化。

- **蒸发损失**：气流在到达某地之前已经沿路径释放了大量水汽，剩余水汽量决定了该地的降水潜力。用指数衰减模型来计算水汽的沿程损耗。

#### 3.3.5 气候分类

获得月均温度和月降水量数据后，使用 Köppen-Geiger 气候分类系统进行气候分类。AtmosSciTools/Koppen-Geiger-ClimateClassification 是一个专门的 Python 库，可以根据温度和降水数据计算气候分类，并可视化月温度降水图（hythergraph）。

Köppen 分类的主要逻辑：

- **A 类（热带）**：最冷月均温 ≥ 18°C
- **B 类（干旱）**：降水量低于阈值，阈值取决于温度和降水季节性
- **C 类（温带）**：最冷月均温 0°C 到 18°C 之间
- **D 类（大陆性）**：最冷月均温 < 0°C，最暖月均温 > 10°C
- **E 类（极地）**：最暖月均温 < 10°C

每类下再根据降水的季节性和具体温度指标细分为子类（如 Cfa = 温带湿润、夏季炎热）。


### 3.4 阶段四：地表系统输出

#### 3.4.1 生物群系与土壤

生物群系由气候分类和地形共同决定。mapwright 已经集成了气候驱动的生物群系生成。土壤类型可以基于经典的成土理论，用母岩、气候、地形、生物和时间五个因素来综合判定。oikoumene 项目在生成地球系统数据时，也通过 f(biome) 函数来计算土壤肥力。

#### 3.4.2 农业类型图

农业类型的分布由气候、土壤和地形共同约束。可以参考 FAO 的农业生态区划（AEZ）框架。PyAEZ 是一个专门的 Python 包，包含气候制度、作物模拟、气候约束、土壤约束、地形约束和经济适宜性分析等模块。

简化的农业类型判定规则示例：

| 气候条件 | 土壤条件 | 地形条件 | 农业类型 |
|---------|---------|---------|---------|
| A类，降水>1500mm | 酸性、贫瘠 | 平原/低地 | 热带种植园（橡胶、可可） |
| A类，降水800-1500mm | 肥沃冲积土 | 平原/河谷 | 水稻种植 |
| B类，有灌溉水源 | 冲积土 | 河流沿岸 | 灌溉农业 |
| C类，降水500-1000mm | 肥沃壤土 | 平原/丘陵 | 谷物种植（小麦、玉米） |
| D类，降水>400mm | 灰化土 | 平原 | 春小麦/马铃薯 |
| E类 | 永久冻土 | — | 无农业/游牧 |

#### 3.4.3 等降水量图

等降水量图的生成相对直接：已有降水网格数据后，使用 Matplotlib 的 `contourf` 或 `contour` 函数绘制等值线图。Isohyet-Map 项目提供了从降水数据创建等值线图的 Notebook 参考。建议使用平滑插值（如样条插值）来避免等值线过于破碎，并使用分级配色方案来增强可读性。

#### 3.4.4 3D 可视化

**方案A：PyVista（推荐用于数据分析）**

PyVista 基于 VTK，支持高质量的 3D 地形渲染、纹理映射和交互操作。pyworldgen 库已经集成了 PyVista 后端。适合生成可旋转、缩放的3D世界视图，可以叠加气候图层作为纹理。

**方案B：Panda3D（推荐用于交互式探索）**

Panda3D 是卡内基梅隆大学开发的开源3D游戏引擎，支持 Python 编程。它的 `GeoMipTerrain` 类可以高效地将高度图转换为3D地形，并支持 LOD（细节层次）优化。适合需要第一人称或第三人称视角漫游世界的场景。

**方案C：Matplotlib 3D + Plotly（推荐用于快速原型）**

对于快速验证和展示，Matplotlib 的 `plot_surface` 或 Plotly 的 `Surface` 足够使用。可以在同一张 3D 地形上叠加不同图层的颜色映射。

## 五、精度与性能策略

### 5.1 分辨率分级

建议采用**分级生成**策略：

- **宏观层**（1°×1°）：大陆轮廓、板块边界、基本气候带。计算速度快，适合全局预览和迭代。
- **中观层**（0.25°×0.25°）：海岸线细节、山脉走向、洋流路径、气候区边界。这是主要的工作分辨率。
- **微观层**（按需 0.05°×0.05°）：仅在用户感兴趣的局部区域生成高精度地形和气候细节。

### 5.2 计算加速

- 使用 NumPy 的向量化操作替代 Python 循环
- 洋流和风场的稳态求解使用 SciPy 的稀疏线性求解器
- 地形扩散模型使用 GPU 加速（CUDA）
- 使用 `joblib` 或 `dask` 进行并行计算（不同纬度带可并行）

### 5.3 确定性保证

整个系统以种子驱动，相同种子 + 相同参数 = 完全相同的结果。ecopoesis 项目采用了统一的 RNG 状态管理模式，所有引擎共享同一个确定性哈希，保证跨语言的一致性。建议在每一个随机数使用点都记录种子，以便复现。

## 七、实施路线图

**第一阶段（2-3周）** ：搭建网格数据模型和行星参数系统，实现基础的地形生成（分形噪声或板块构造），完成海拔网格和海洋掩码。

**第二阶段（3-4周）** ：实现温度场和气压场的诊断式计算，包括纬度效应、海拔递减、大陆性效应。完成一月和七月温度图。

**第三阶段（3-4周）** ：实现风场和洋流的简化动力学模拟，完成气压带风带图和洋流图。加入洋流对温度的反馈修正。

**第四阶段（2-3周）** ：实现多机制降水模型，完成等降水量图和 Köppen 气候分类。

**第五阶段（2-3周）** ：基于气候和地形数据生成生物群系、土壤类型和农业类型图。

**第六阶段（2-3周）** ：3D 可视化渲染，可选 PyVista（分析向）或 Panda3D（探索向）。

**第七阶段（1-2周）** ：参数调优、精度验证（检查气候分类是否与地形-气候耦合关系自洽）、性能优化。

这个方案的核心优势在于**物理因果链的完整性**：每一步的输出都基于前一步的结果，而不是独立生成各图层。这保证了虚拟世界的内在一致性——山脉确实会导致背风坡干旱，寒流沿岸确实会形成沙漠，赤道确实会形成湿润的热带气候。
