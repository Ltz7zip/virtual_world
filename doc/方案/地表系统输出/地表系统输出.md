# 阶段四：地表系统输出

## 一、总体框架

地表系统输出是完整气候管线的**最终诊断层**。它接收气候模拟的全部输出场（温度、降水、气压、风、洋流、辐射），结合地形和土壤基底，生成具有**生态意义**和**地理保真度**的地表分类图与可视化。

与前三个阶段不同，这一阶段**不涉及时间积分**，全部是**诊断式规则判定**和**空间插值**。但保真度的挑战在于：地表系统的分类边界必须与气候场保持**物理一致**——沙漠必须在副热带高压带，雨林必须在ITCZ，苔原必须在极地。任何分类结果如果违反这些因果约束，就说明气候模拟或分类逻辑存在问题。

输出模块分为五个层级：

**层级一：生物群系**——基于气候和地形的生态分类。
**层级二：土壤类型**——基于气候、母质、地形、生物的成土分类。
**层级三：农业类型**——基于气候、土壤、地形的农业生态区划。
**层级四：2D专题地图**——等降水量图、气候分类图、气压带风带图等。
**层级五：3D可视化**——交互式3D世界渲染。


## 二、生物群系模型

### 2.1 生物群系的数学定义

生物群系是**气候-植被-土壤**耦合系统的宏观分类单元。其数学定义基于**Holdridge生命带模型**和**Whittaker图**的联合约束。

**Holdridge模型**用三个气候变量定义生命带：

- **生物温度** \( T_{\text{bio}} \)：\( T_{\text{bio}} = \frac{1}{12}\sum_{m=1}^{12} \min(T_m, 30°\text{C}) \)，单位 °C。超过 30°C 的温度被截断，因为植物光合作用在高温下饱和。
- **年降水量** \( P \)：mm。
- **可能蒸散率** \( \text{PET} \)：由 \( T_{\text{bio}} \) 计算，\( \text{PET} = 58.93 \times T_{\text{bio}} \)，单位 mm/年。

由此定义**湿度省**：

\[
\text{湿度省} = \frac{P}{\text{PET}}
\]

Holdridge的湿度省划分：

| 湿度省 | \( P/\text{PET} \) | 气候特征 |
|--------|-------------------|---------|
| 极干 | < 0.125 | 沙漠 |
| 干旱 | 0.125–0.25 | 荒漠草原 |
| 半干旱 | 0.25–0.5 | 草原 |
| 半湿润 | 0.5–1.0 | 疏林/稀树草原 |
| 湿润 | 1.0–2.0 | 森林 |
| 极湿 | > 2.0 | 雨林 |

**纬度生命带**由 \( T_{\text{bio}} \) 划分：

| 生命带 | \( T_{\text{bio}} \) (°C) |
|--------|--------------------------|
| 极地 | < 1.5 |
| 苔原 | 1.5–3 |
| 北方针叶林 | 3–6 |
| 冷温带 | 6–12 |
| 暖温带 | 12–18 |
| 亚热带 | 18–24 |
| 热带 | > 24 |

### 2.2 Whittaker图的数学表达

**Whittaker图**用年均温（MAT）和年降水量（MAP）直接划分生物群系。其边界可以用**分段线性函数**精确表达：

**苔原/北方针叶林边界**：

\[
\text{MAP}_{\text{boundary}} = \begin{cases}
200 & \text{MAT} < -5°\text{C} \\
200 + 100(\text{MAT} + 5) & -5°\text{C} \leq \text{MAT} \leq 0°\text{C} \\
700 & \text{MAT} > 0°\text{C}
\end{cases}
\]

**北方针叶林/温带森林边界**：

\[
\text{MAP}_{\text{boundary}} = 400 + 50(\text{MAT} - 3)
\]

**温带森林/温带草原边界**：

\[
\text{MAP}_{\text{boundary}} = 2 \times \text{MAT} + 200
\]

**温带草原/沙漠边界**：

\[
\text{MAP}_{\text{boundary}} = \max(0, 2 \times \text{MAT})
\]

**热带雨林/热带季雨林边界**：

\[
\text{MAP}_{\text{boundary}} = 2000 \, \text{mm}
\]

### 2.3 生物群系的综合判定算法

将 Holdridge 和 Whittaker 的结果**交叉验证**，取两者的**交集**作为最终分类。当两者冲突时，以**水分限制**优先（因为水分是生物群系边界的首要控制因子）。

```python
def classify_biome(T_monthly, P_monthly, elevation, lat):
    """
    输入：月温度 (°C), 月降水 (mm), 海拔 (m), 纬度
    输出：生物群系代码
    """
    MAT = T_monthly.mean(axis=0)
    MAP = P_monthly.sum(axis=0)
    T_bio = np.minimum(T_monthly, 30).mean(axis=0)
    PET = 58.93 * T_bio
    humidity = MAP / (PET + 1e-6)
    
    # Holdridge 生命带
    holdridge = np.where(T_bio < 1.5, 'polar',
                np.where(T_bio < 3, 'tundra',
                np.where(T_bio < 6, 'boreal',
                np.where(T_bio < 12, 'cool_temperate',
                np.where(T_bio < 18, 'warm_temperate',
                np.where(T_bio < 24, 'subtropical', 'tropical'))))))
    
    # Whittaker 湿度分类
    whittaker = np.where(MAP < 2*MAT, 'desert',
                np.where(MAP < 2*MAT + 200, 'grassland',
                np.where(MAP < 400 + 50*(MAT-3), 'temperate_forest',
                np.where(MAP < 2000, 'temperate_rainforest', 'tropical_rainforest'))))
    
    # 海拔修正（高山生物群系）
    elevation_biome = np.where(elevation > 4000, 'alpine',
                      np.where(elevation > 2500, 'subalpine', 'none'))
    
    # 综合判定（海拔优先，水分其次，温度最后）
    biome = np.where(elevation_biome != 'none', elevation_biome, 
            np.where(whittaker == 'desert', 'desert',
            np.where(whittaker == 'grassland', 'grassland',
            np.where(holdridge == 'tundra', 'tundra',
            np.where(holdridge == 'boreal', 'boreal_forest',
            np.where(holdridge == 'tropical', 'tropical_forest',
            np.where(holdridge == 'subtropical', 'subtropical_forest',
            np.where(holdridge == 'warm_temperate', 'temperate_forest',
                     'cool_temperate_forest'))))))))
    
    return biome
```

### 2.4 生物群系的地理保真度检验

**纬度约束**：

- 热带雨林只出现在 \( |\phi| < 15° \)
- 北方针叶林只出现在 \( |\phi| > 45° \)（北半球）
- 苔原只出现在 \( |\phi| > 60° \)

**海陆约束**：

- 沙漠不应出现在大陆西岸的湿润区（除非有寒流）
- 雨林不应出现在副热带高压带（除非有地形抬升）

**地形约束**：

- 高山生物群系必须与海拔 > 2500 m 一致
- 背风坡应比迎风坡更干旱

**洋流约束**：

- 寒流沿岸应比同纬度其他地区更干旱
- 暖流沿岸应比同纬度其他地区更湿润


## 三、土壤类型模型

### 3.1 CLORPT 因子方程

**Jenny (1941) 的 CLORPT 方程**是土壤形成的经典框架：

\[
S = f(Cl, O, R, P, T)
\]

其中：

- \( Cl \) = 气候（climate）
- \( O \) = 生物（organisms）
- \( R \) = 地形（relief）
- \( P \) = 母质（parent material）
- \( T \) = 时间（time）

在虚拟世界生成器中，土壤类型可以简化为**气候和地形的函数**（母质假定均匀，时间假定充分）：

\[
S(\lambda, \phi) = f(\text{MAT}, \text{MAP}, \text{PET}, \text{elevation}, \text{slope}, \text{drainage})
\]

### 3.2 土壤分类的数学表达

采用 **WRB（World Reference Base）** 的简化版本，主要土壤类型及其形成条件：

**砖红壤/铁铝土（Ferralsols）** ：

- 条件：\( \text{MAT} > 22°\text{C} \)，\( \text{MAP} > 1500 \) mm，强淋溶
- 特征：铁铝氧化物富集，酸性，贫瘠

**红壤/强淋溶土（Acrisols）** ：

- 条件：\( \text{MAT} > 15°\text{C} \)，\( \text{MAP} > 1000 \) mm
- 特征：中度淋溶，黏粒迁移

**棕壤/始成土（Cambisols）** ：

- 条件：温带，\( \text{MAP} \) 500–1000 mm
- 特征：中度风化，结构良好

**黑钙土（Chernozems）** ：

- 条件：温带草原，\( \text{MAT} \) 5–15°C，\( \text{MAP} \) 300–600 mm
- 特征：有机质丰富，钙积层

**灰化土（Podzols）** ：

- 条件：冷温带针叶林，\( \text{MAT} < 8°\text{C} \)，\( \text{MAP} > 500 \) mm
- 特征：酸性，有机质-铁铝络合淋溶

**永冻土（Cryosols）** ：

- 条件：\( \text{MAT} < 0°\text{C} \)，有永久冻土
- 特征：冻融扰动，有机质积累

**盐碱土（Solonchaks/Solonetz）** ：

- 条件：干旱区，\( \text{PET} \gg P \)，地下水位高
- 特征：盐分积累

**冲积土（Fluvisols）** ：

- 条件：河流沿岸，周期性泛滥
- 特征：层状沉积，肥力较高

### 3.3 土壤属性的定量预测

**土壤有机碳**（SOC）由气候和生物群系决定：

\[
\text{SOC} = f(T, P) \cdot g(\text{biome}) \cdot h(\text{clay})
\]

简化模型：

\[
\text{SOC} = 1000 \cdot \exp\left( -0.02 T + 0.003 P \right) \cdot \text{SOC}_{\text{biome}}
\]

其中 \( \text{SOC}_{\text{biome}} \) 是生物群系特定的系数：热带雨林 0.5，温带森林 1.0，草原 1.5，苔原 2.0。

**土壤 pH**：

\[
\text{pH} = \text{pH}_0 - 0.5 \cdot \frac{\text{MAP}}{\text{PET}} + 0.3 \cdot \frac{\text{MAT}}{10}
\]

**土壤阳离子交换量**（CEC）：

\[
\text{CEC} = a \cdot \text{clay} + b \cdot \text{SOC}
\]

### 3.4 土壤类型的空间分配

```python
def classify_soil(MAT, MAP, PET, elevation, slope, drainage):
    """
    简化的土壤分类
    """
    # 永冻土
    soil = np.where(MAT < 0, 'Cryosols',
           # 灰化土
           np.where((MAT < 8) & (MAP > 500) & (MAT >= 0), 'Podzols',
           # 黑钙土
           np.where((MAT >= 3) & (MAT < 15) & (MAP >= 300) & (MAP < 600), 'Chernozems',
           # 砖红壤
           np.where((MAT > 22) & (MAP > 1500), 'Ferralsols',
           # 红壤
           np.where((MAT > 15) & (MAP > 1000), 'Acrisols',
           # 盐碱土
           np.where((PET > 2*MAP) & (drainage < 0.2), 'Solonchaks',
           # 冲积土
           np.where(drainage > 0.8, 'Fluvisols',
           # 棕壤（默认温带）
                    'Cambisols'))))))))
    
    # 坡度修正（陡坡薄层土）
    soil = np.where(slope > 30, 'Leptosols', soil)
    
    return soil
```


## 四、农业类型模型

### 4.1 FAO 农业生态区划框架

**FAO 农业生态区划（AEZ）** 是农业类型分类的国际标准。其核心逻辑是：**气候 → 土壤 → 地形 → 作物适宜性 → 农业类型**。

**气候约束**：每种作物有**温度下限、温度上限、降水下限、降水上限**。作物适宜性指数为：

\[
\text{SI} = f_T(T) \cdot f_P(P) \cdot f_{\text{soil}}(S) \cdot f_{\text{terrain}}(H)
\]

**温度响应函数**（以小麦为例）：

\[
f_T(T) = \begin{cases}
0 & T < T_{\min} \\
\frac{T - T_{\min}}{T_{\text{opt}} - T_{\min}} & T_{\min} \leq T < T_{\text{opt}} \\
\frac{T_{\max} - T}{T_{\max} - T_{\text{opt}}} & T_{\text{opt}} \leq T < T_{\max} \\
0 & T \geq T_{\max}
\end{cases}
\]

**降水响应函数**：

\[
f_P(P) = \exp\left( -\frac{(P - P_{\text{opt}})^2}{2\sigma_P^2} \right)
\]

### 4.2 主要农业类型的判定规则

| 农业类型 | 气候条件 | 土壤条件 | 地形条件 |
|---------|---------|---------|---------|
| **热带种植园** | \( \text{MAT} > 22°\text{C} \)，\( \text{MAP} > 1500 \) mm | 酸性、贫瘠 | 平原/低地 |
| **水稻种植** | \( \text{MAT} > 18°\text{C} \)，\( \text{MAP} > 800 \) mm | 冲积土、黏土 | 河谷/平原 |
| **灌溉农业** | \( \text{MAT} > 10°\text{C} \)，有水源 | 冲积土 | 河流沿岸 |
| **谷物种植** | \( \text{MAT} \) 5–20°C，\( \text{MAP} \) 400–1000 mm | 肥沃壤土 | 平原/丘陵 |
| **春小麦** | \( \text{MAT} \) 0–10°C，\( \text{MAP} > 300 \) mm | 灰化土 | 平原 |
| **游牧** | \( \text{MAT} \) 0–15°C，\( \text{MAP} < 300 \) mm | 干旱土 | 草原 |
| **无农业** | \( \text{MAT} < 0°\text{C} \) 或 \( \text{MAP} < 100 \) mm | 永冻土/沙漠 | — |

### 4.3 农业类型的空间分配

```python
def classify_agriculture(MAT, MAP, soil, elevation, slope, river_proximity):
    """
    农业类型分类（简化版）
    """
    # 无农业区
    agri = np.where((MAT < 0) | (MAP < 100), 'none',
           # 游牧
           np.where(MAP < 300, 'pastoralism',
           # 热带种植园
           np.where((MAT > 22) & (MAP > 1500) & (soil == 'Ferralsols'), 'plantation',
           # 水稻
           np.where((MAT > 18) & (MAP > 800) & (slope < 5), 'rice',
           # 灌溉农业
           np.where((MAT > 10) & (river_proximity < 0.1), 'irrigated',
           # 谷物
           np.where((MAT > 5) & (MAT < 20) & (MAP > 400) & (MAP < 1000), 'cereal',
           # 春小麦
           np.where((MAT < 10) & (MAP > 300), 'spring_wheat',
                    'mixed'))))))))
    
    # 陡坡修正（梯田或林地）
    agri = np.where(slope > 25, 'terracing_or_forest', agri)
    
    return agri
```


## 五、2D 专题地图

### 5.1 等降水量图

等降水量图使用**等值线**表示降水分布。生成步骤：

1. **平滑插值**：用**高斯滤波**平滑降水场，避免等值线过于破碎：
   \[
   P_{\text{smooth}} = P * G_\sigma
   \]
   其中 \( G_\sigma \) 是高斯核，\( \sigma \) 通常取 1–2 个网格间距。

2. **等值线提取**：用 **Marching Squares 算法**从平滑场提取等值线。Matplotlib 的 `contour` 和 `contourf` 函数直接支持。

3. **分级配色**：使用**分级配色方案**（如 0–100, 100–200, ..., >2000 mm），增强可读性。

### 5.2 气候分类图

气候分类图用**离散颜色**表示 Köppen 代码。配色方案遵循标准：

- A 类：绿色系（深绿 Af, 中绿 Am, 浅绿 Aw）
- B 类：黄色-红色系（黄 BS, 红 BW）
- C 类：蓝色-绿色系
- D 类：紫色-蓝色系
- E 类：灰色-白色系

### 5.3 气压带风带图

气压带风带图用**流线**表示风场，用**等值线**表示气压。流线用 **Matplotlib 的 `streamplot`** 生成，气压等值线用 `contour`。

**流线的数学基础**：流线是速度场的积分曲线，满足：
\[
\frac{d\mathbf{x}}{ds} = \mathbf{u}(\mathbf{x})
\]

Matplotlib 的 `streamplot` 用 **Runge-Kutta 方法**数值积分流线。

### 5.4 洋流图

洋流图用**箭头**表示洋流方向和速度。箭头长度和颜色编码速度大小。用 `quiver` 函数绘制。

### 6.2 MLX 加速渲染（MacBook Pro 2024 推荐）

在 Apple Silicon 上，用 **MLX** 加速地形网格的生成和着色计算：

```python
import mlx.core as mx

def compute_terrain_normals(elevation):
    """MLX GPU 加速的法向量计算"""
    dz_dx = mx.gradient(elevation, axis=1)
    dz_dy = mx.gradient(elevation, axis=0)
    normals = mx.stack([-dz_dx, -dz_dy, mx.ones_like(elevation)], axis=-1)
    normals = normals / mx.linalg.norm(normals, axis=-1, keepdims=True)
    return normals
```

法向量计算是 3D 渲染的核心，MLX GPU 加速可以实时处理千万级网格点。


## 七、验证与保真度

### 7.1 生态一致性检验

**降水-生物群系一致性**：

- 热带雨林：\( \text{MAP} > 2000 \) mm，\( T_{\text{cold}} > 18°\text{C} \)
- 沙漠：\( \text{MAP} < 250 \) mm，\( \text{PET} > 2\text{MAP} \)
- 苔原：\( T_{\text{hot}} < 10°\text{C} \)

**温度-生物群系一致性**：

- 北方针叶林：\( \text{MAT} \) 0–8°C
- 温带森林：\( \text{MAT} \) 8–20°C
- 热带森林：\( \text{MAT} > 20°\text{C} \)

### 7.2 地理合理性检验

**纬度约束**：

- 苔原不应出现在 \( |\phi| < 45° \)
- 热带雨林不应出现在 \( |\phi| > 25° \)

**海陆约束**：

- 沙漠不应出现在大陆东岸的湿润区
- 雨林不应出现在副热带高压带

**洋流约束**：

- 寒流沿岸的降水应比同纬度低 30% 以上
- 暖流沿岸的降水应比同纬度其他地区高 20% 以上

### 7.3 多尺度一致性

生物群系、土壤、农业类型在同一网格点上应**逻辑一致**：

- 如果生物群系是“沙漠”，土壤不应是“冲积土”，农业不应是“水稻”
- 如果生物群系是“热带雨林”，土壤应是“砖红壤”或“红壤”，农业应是“热带种植园”

```python
        np.where(MAP < 2*MAT, 'desert',
        np.where(MAP < 2*MAT + 200, 'grassland',
        np.where(T_bio < 3, 'tundra',
        np.where(T_bio < 6, 'boreal_forest',
                 'temperate_forest')))))
```

### 8.5 3D 渲染的加速

**法向量计算**用 MLX GPU：

```python
def compute_normals_gpu(elevation):
    dz_dx = mx.gradient(elevation, axis=1)
    dz_dy = mx.gradient(elevation, axis=0)
    normals = mx.stack([-dz_dx, -dz_dy, mx.ones_like(elevation)], axis=-1)
    normals = normals / mx.linalg.norm(normals, axis=-1, keepdims=True)
    return normals
```

## 十、实践建议

**先低分辨率跑通**。在 5° 分辨率上验证生物群系、土壤和农业类型的分类逻辑是否与气候场一致。确认无误后再提高分辨率。

**缓存分类结果**。生物群系、土壤和农业类型的分类结果是静态的（不随时间变化），用 **Zarr** 缓存，避免重复计算。

**视觉检验**。将生物群系图与温度、降水图叠加，检查是否存在“沙漠出现在湿润区”或“雨林出现在副热带高压带”等物理不一致。

**与真实地球对比**。在地球参数下运行完整管线，将输出的生物群系图与真实地球的生物群系图（如 WWF 的 Terrestrial Ecoregions）对比。如果撒哈拉、亚马逊、西伯利亚针叶林的位置大致正确，说明管线物理合理。
