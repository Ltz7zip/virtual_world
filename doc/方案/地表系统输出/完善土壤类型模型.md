# 完善土壤类型模型

## 一、总体架构：从CLORPT到过程模型

土壤类型模型的核心挑战在于：土壤是**气候、生物、地形、母质和时间**五因素长期相互作用的产物。在虚拟世界生成器中，母质（假定均匀）和时间（假定充分）可以固定，土壤类型因此简化为**气候与地形的函数**：

\[
S(\lambda, \phi) = f(\text{MAT}, \text{MAP}, \text{PET}, \text{elevation}, \text{slope}, \text{drainage})
\]

但简单的查表无法保证物理保真度。本模型采用**三层架构**：

**第一层：成土过程诊断**。基于Jenny的CLORPT框架，计算淋溶强度、有机质积累、盐分积累等**诊断指标**，这些指标直接对应土壤形成的关键过程。

**第二层：WRB分类判定**。基于**世界土壤参考基准（WRB）** 的诊断层和诊断特性，将诊断指标映射为土壤类型。WRB的分类标准高度量化，适合算法实现。

**第三层：土壤属性预测**。用**数字土壤制图**的方法，从环境协变量预测土壤有机碳（SOC）、pH、阳离子交换量（CEC）等关键属性。


## 二、第一层：成土过程诊断指标

### 2.1 淋溶强度：铁铝氧化物富集

**淋溶强度**（Leaching Index, LI）量化了降水对可溶性盐基离子的淋洗程度，是区分砖红壤、红壤、棕壤的关键：

\[
\text{LI} = \frac{\text{MAP}}{\text{PET}} \cdot \exp\left(-\frac{T_{\text{avg}}}{20}\right)
\]

其中 \( \text{PET} = 58.93 \cdot T_{\text{bio}} \)，与Holdridge模型一致。LI 的物理含义是**水分盈余与温度驱动的风化速率的乘积**。

**LI 的判定阈值**：

| LI 范围 | 淋溶程度 | 对应土壤特征 |
|---------|---------|-------------|
| < 0.3 | 极弱 | 盐碱土、钙积土 |
| 0.3–0.8 | 弱 | 黑钙土、栗钙土 |
| 0.8–1.5 | 中等 | 棕壤、始成土 |
| 1.5–3.0 | 强 | 红壤、强淋溶土 |
| > 3.0 | 极强 | 砖红壤、铁铝土 |

### 2.2 有机质积累指数

**有机质积累指数**（OMAI）量化了生物量输入与分解速率的平衡：

\[
\text{OMAI} = \frac{\text{NPP}}{k_{\text{decomp}}(T, W)}
\]

其中 NPP 是净初级生产力（来自生物群系模块），\( k_{\text{decomp}} \) 是分解速率：

\[
k_{\text{decomp}} = k_0 \cdot \exp\left(\frac{E_a}{R}\left(\frac{1}{T_0} - \frac{1}{T}\right)\right) \cdot f_{\text{water}}(W)
\]

\( E_a \approx 50 \, \text{kJ/mol} \) 是活化能，\( f_{\text{water}}(W) \) 是水分修正函数。OMAI > 1 表示有机质积累（黑钙土、灰化土），OMAI < 1 表示有机质分解快（砖红壤）。

### 2.3 盐分积累指数

**盐分积累指数**（SAI）量化了蒸发浓缩导致的盐分表聚：

\[
\text{SAI} = \frac{\text{PET} - \text{MAP}}{\text{PET}} \cdot \text{drainage}_{\text{deficiency}}
\]

其中 \( \text{drainage}_{\text{deficiency}} = \max(0, 1 - \text{drainage}) \)。SAI > 0.5 表示盐碱化风险高。

### 2.4 黏粒迁移指数

**黏粒迁移指数**（CMI）量化了黏粒从表层向下迁移的程度（淋溶层/淀积层的形成）：

\[
\text{CMI} = \text{LI} \cdot \frac{\text{clay}_{\text{content}}}{100} \cdot f_{\text{seasonality}}
\]

\( f_{\text{seasonality}} \) 是干湿交替频率的修正函数，干湿交替越频繁，黏粒迁移越强。


## 三、第二层：WRB分类的量化判定

### 3.1 WRB诊断层与诊断特性

WRB分类基于**诊断层**（diagnostic horizons）和**诊断特性**（diagnostic properties）。对于虚拟世界生成器，主要诊断层包括：

**有机质层（Mollic/Histic）** ：表层有机碳含量高、盐基饱和度高。

**淋溶层（Albic）** ：黏粒和铁铝氧化物被淋失，颜色浅。

**淀积层（Argic）** ：黏粒积累，黏粒含量比上覆层高 1.2 倍以上。

**铁铝层（Ferralic）** ：铁铝氧化物富集，CEC < 16 cmol/kg。

**钙积层（Calcic）** ：碳酸钙积累，CaCO₃ 含量 > 15%。

**盐积层（Salic）** ：可溶性盐积累，电导率 > 15 dS/m。

### 3.2 土壤类型的量化判定规则

基于诊断指标和诊断层，土壤类型的判定规则如下：

**砖红壤（Ferralsols）** ：LI > 3.0，CMI > 2.0，CEC < 16 cmol/kg。

**强淋溶土（Acrisols）** ：LI 1.5–3.0，CMI > 1.5，盐基饱和度 < 50%。

**始成土（Cambisols）** ：LI 0.8–1.5，无强诊断层。

**黑钙土（Chernozems）** ：OMAI > 1.5，MAT 5–15°C，MAP 300–600 mm，Mollic 层。

**灰化土（Podzols）** ：MAT < 8°C，MAP > 500 mm，Albic 层 + 铁铝淀积层。

**钙积土（Calcisols）** ：SAI 0.3–0.5，Calcic 层。

**盐碱土（Solonchaks/Solonetz）** ：SAI > 0.5，Salic 层。

**永冻土（Cryosols）** ：MAT < 0°C，有永久冻土。

**冲积土（Fluvisols）** ：河流沿岸，周期性泛滥，层状沉积。

### 3.3 模糊推理判定

WRB的许多标准需要量化，但实际土壤属性存在**渐变过渡**。采用**模糊推理**方法：定义每个诊断指标的**隶属度函数**，用**组合推理规则**进行土壤聚类。

```python
def fuzzy_ferralsol(LI, CMI, CEC):
    """砖红壤的模糊隶属度"""
    mu_LI = sigmoid(LI, center=3.0, width=0.5)
    mu_CMI = sigmoid(CMI, center=2.0, width=0.3)
    mu_CEC = 1 - sigmoid(CEC, center=16, width=4)
    return mu_LI * mu_CMI * mu_CEC

def fuzzy_chernozem(OMAI, MAT, MAP):
    """黑钙土的模糊隶属度"""
    mu_OM = sigmoid(OMAI, center=1.5, width=0.3)
    mu_T = gaussian(MAT, center=10, width=5)
    mu_P = gaussian(MAP, center=450, width=150)
    return mu_OM * mu_T * mu_P
```

最终分类为**隶属度最大的土壤类型**。

### 3.4 综合分类算法

```python
def classify_soil_advanced(T_monthly, P_monthly, elevation, slope, 
                           drainage, NPP, river_proximity):
    """
    完整土壤分类管线
    """
    MAT = T_monthly.mean(axis=0)
    MAP = P_monthly.sum(axis=0)
    T_bio = compute_biotemperature(T_monthly)
    PET = 58.93 * T_bio
    
    # ===== 第一层：诊断指标 =====
    LI = (MAP / (PET + 1e-6)) * np.exp(-MAT / 20)
    OMAI = NPP / (decomposition_rate(MAT, MAP) + 1e-6)
    SAI = ((PET - MAP) / (PET + 1e-6)) * np.maximum(0, 1 - drainage)
    CMI = LI * clay_content_factor(MAT, MAP)
    
    # ===== 第二层：模糊判定 =====
    membership = {
        'Ferralsols': fuzzy_ferralsol(LI, CMI, CEC_estimate(MAT, MAP)),
        'Acrisols': fuzzy_acrisols(LI, CMI, MAP),
        'Chernozems': fuzzy_chernozem(OMAI, MAT, MAP),
        'Podzols': fuzzy_podzol(MAT, MAP, OMAI),
        'Calcisols': fuzzy_calcisol(SAI, MAT, MAP),
        'Solonchaks': fuzzy_solonchak(SAI, drainage),
        'Cryosols': fuzzy_cryosol(MAT),
        'Fluvisols': fuzzy_fluvisol(river_proximity),
    }
    
    # 选择隶属度最大的类型
    soil_type = max(membership, key=membership.get)
    
    # ===== 第三层：地理修正 =====
    soil_type = np.where(slope > 30, 'Leptosols', soil_type)  # 陡坡薄层土
    soil_type = np.where(elevation > 4000, 'Leptosols', soil_type)
    
    return soil_type
```


## 四、第三层：土壤属性预测

### 4.1 土壤有机碳（SOC）

SOC是土壤最重要的属性之一。基于**RothC模型**的温度和水分响应函数框架，简化的平衡态SOC模型为：

\[
\text{SOC} = \text{NPP} \cdot \frac{f_{\text{temp}}(T) \cdot f_{\text{moist}}(W)}{k_{\text{base}}}
\]

其中温度响应函数 \( f_{\text{temp}}(T) = \exp\left(\frac{E_a}{R}\left(\frac{1}{T_{\text{ref}}} - \frac{1}{T}\right)\right) \)。**关键发现**：温度响应函数的选取会导致深层SOC模拟偏差高达 **30%**，水分响应函数会导致表层SOC偏差高达 **37%**。因此，对于虚拟行星的不同大气成分和温度范围，需要重新标定这些响应函数。

### 4.2 土壤pH

基于气候和土壤类型的简化pH模型：

\[
\text{pH} = \text{pH}_{\text{base}} - 0.5 \cdot \text{LI} + 0.3 \cdot \frac{\text{MAT}}{10}
\]

其中 \( \text{pH}_{\text{base}} \) 是土壤类型的基准值：砖红壤 5.0，红壤 5.5，棕壤 6.5，黑钙土 7.0，钙积土 8.0，盐碱土 9.0。

### 4.3 阳离子交换量（CEC）

CEC与有机质和黏粒含量密切相关。基于回归分析的经验模型：

\[
\text{CEC} = -13.93 + 2.645 \cdot \text{pH} + 0.0446 \cdot C(\%) + 2.267 \cdot \text{SOC}(\%)
\]

简化版本：

\[
\text{CEC} = a \cdot \text{clay} + b \cdot \text{SOC}
\]

其中 \( a \approx 0.5 \)，\( b \approx 2.0 \)。


## 五、地理约束与保真度检验

### 5.1 纬度约束

| 土壤类型 | 允许纬度范围 | 物理依据 |
|---------|-------------|---------|
| 砖红壤 | \( |\phi| < 25° \) | 高温高湿淋溶 |
| 灰化土 | \( |\phi| > 45° \) | 冷湿针叶林 |
| 永冻土 | \( |\phi| > 60° \) | 永久冻土 |
| 黑钙土 | 中纬度草原 | 半湿润半干旱 |

### 5.2 海陆与洋流约束

- 寒流沿岸：沙漠土（干旱土）替代同纬度的棕壤
- 暖流沿岸：砖红壤/红壤的纬度界限向极地延伸

### 5.3 多尺度一致性

土壤类型必须与**生物群系**和**农业类型**逻辑一致：

- 沙漠 → 干旱土 → 游牧/无农业
- 热带雨林 → 砖红壤 → 热带种植园
- 温带草原 → 黑钙土 → 谷物种植
- 北方针叶林 → 灰化土 → 春小麦/林业


## 六、加速方案

### 6.1 计算热点分析

土壤分类的计算热点在**模糊隶属度计算**和**属性预测**。1° 分辨率（65,000网格点）× 8个土壤类型 × 3个诊断指标 = \( 1.56 \times 10^6 \) 次模糊运算。

将整个模糊推理和属性预测搬到GPU：

```python
import mlx.core as mx

def classify_soil_gpu(T_monthly, P_monthly, NPP, drainage):
    MAT = mx.mean(T_monthly, axis=0)
    MAP = mx.sum(P_monthly, axis=0)
    T_bio = mx.mean(mx.where((T_monthly > 0) & (T_monthly < 30), 
                              T_monthly, 0), axis=0)
    PET = 58.93 * T_bio
    
    LI = (MAP / (PET + 1e-6)) * mx.exp(-MAT / 20)
    OMAI = NPP / (decomposition_rate_gpu(MAT, MAP) + 1e-6)
    SAI = ((PET - MAP) / (PET + 1e-6)) * mx.maximum(0, 1 - drainage)
    
    # 模糊隶属度（全向量化）
    mu_ferralsol = sigmoid_gpu(LI, 3.0, 0.5) * sigmoid_gpu(CMI, 2.0, 0.3)
    mu_chernozem = sigmoid_gpu(OMAI, 1.5, 0.3) * gaussian_gpu(MAT, 10, 5)
    # ... 所有土壤类型
    
    # 选择最大隶属度
    membership_stack = mx.stack([mu_ferralsol, mu_chernozem, ...], axis=0)
    soil_code = mx.argmax(membership_stack, axis=0)
    
    return soil_code
```

## 七、完整土壤分类管线

```
输入：T_monthly, P_monthly, NPP, elevation, slope, drainage, river_proximity

=== 第一层：成土过程诊断 ===
1. 计算 MAT, MAP, T_bio, PET
2. 计算淋溶指数 LI = (MAP/PET) × exp(-MAT/20)
3. 计算有机质积累指数 OMAI = NPP / k_decomp
4. 计算盐分积累指数 SAI = ((PET-MAP)/PET) × (1-drainage)
5. 计算黏粒迁移指数 CMI = LI × clay_factor

=== 第二层：WRB模糊判定 ===
6. 对每个土壤类型计算模糊隶属度
7. 选择隶属度最大的类型
8. 地理修正：陡坡→薄层土，高海拔→薄层土

=== 第三层：属性预测 ===
9. SOC = NPP × f_temp × f_moist / k_base
10. pH = pH_base - 0.5×LI + 0.3×MAT/10
11. CEC = a×clay + b×SOC

=== 输出 ===
12. soil_type(λ, φ)：土壤类型图
13. SOC(λ, φ)：有机碳分布图
14. pH(λ, φ)：酸碱度分布图
15. CEC(λ, φ)：阳离子交换量图
16. 与生物群系的一致性检验
```

这个管线的输出是**具有物理基础的土壤类型图**，与生物群系和农业类型保持逻辑一致，闭合了从行星辐射强迫到地表土壤系统的完整因果链。
