# 完善验证与保真度

## 一、总体架构：五层验证体系

验证与保真度是虚拟世界生成器的**质量保证层**。它需要在多个尺度、多个物理量上系统地检验生成结果的**物理自洽性、数值正确性和地理合理性**。本模块采用五层验证架构：

**第一层：守恒律诊断**。检验能量、质量、角动量、涡度等物理量的守恒性，这是数值方案保真度的核心判据。

**第二层：动力学一致性检验**。检验地转平衡、热成风平衡、位涡守恒等动力学关系是否在模型输出中成立。

**第三层：地理与物理一致性**。检验各气候场之间（温度-降水-气压-风-洋流）的因果关系是否逻辑一致。

**第四层：生态一致性**。检验生物群系、土壤、农业类型与气候场的一致性，以及Köppen分布的合理性。

**第五层：基准测试**。在地球参数下运行，与真实地球观测数据对比，量化模型偏差。


## 二、第一层：守恒律诊断

### 2.1 能量守恒诊断

大气总能量（动能 + 内能 + 位能）的守恒方程为：

\[
\frac{d}{dt}\int \rho \left( \frac{|\mathbf{u}|^2}{2} + c_v T + \Phi \right) dV = \text{净辐射输入} + \text{表面通量}
\]

在谱空间中，能量积分可表达为：

\[
\text{Energy/Unit mass} = \frac{a^2}{\sqrt{2}p_0^0}\int \sum_{m=-J}^{+J}\sum_{l=|m|}^{|m|+J} p_l^{m*}\left\{E_l^m + \Phi_l^m + \frac{c_v}{a^2} T_l^m\right\} \partial\sigma
\]

其中 \( p_l^m \) 是表面气压的谱系数。**验证标准**：在无辐射强迫的绝热积分中，全球总能量的漂移率应小于 **0.1%/天**。历史谱模型的实测数据表明，96小时积分中总能量变化约 **-0.013%**，角动量变化约 **+0.170%**，表面气压变化约 **-0.027%**。

**诊断方法**：

```python
def diagnose_energy_conservation(state_history):
    """诊断能量守恒"""
    energy = []
    for state in state_history:
        u, v, T, ps = state['u'], state['v'], state['T'], state['ps']
        KE = 0.5 * (u**2 + v**2)
        IE = c_v * T
        PE = g * z_geopotential
        total = integrate_over_sphere(KE + IE + PE, ps)
        energy.append(total)
    drift_rate = (energy[-1] - energy[0]) / energy[0] / t_total
    return drift_rate
```

### 2.2 质量守恒诊断

大气干空气质量应严格守恒。表面气压的全球积分即为干空气质量：

\[
M_{\text{dry}} = \frac{1}{g}\int p_s \cos\phi \, d\phi \, d\lambda
\]

**验证标准**：在时间积分中，\( M_{\text{dry}} \) 的相对变化应小于 **10⁻⁶/天**。干空气质量（而非湿空气质量）是近似守恒的量，因为水汽的源汇不改变干空气质量。

### 2.3 角动量守恒诊断

大气总角动量包括**相对角动量**和**行星角动量**：

\[
\text{Angular momentum} = a(U + \Omega a\cos^2\phi)
\]

其中 \( U \) 是纬向风，\( \Omega \) 是行星自转角速度。角动量的变化仅通过**外部力矩**（地形力矩和摩擦力矩）和**跨边界通量**发生。

**验证标准**：在无地形、无摩擦的绝热积分中，总角动量应严格守恒。在实际模型中，角动量漂移应小于 **1%/天**。历史模型的实测角动量变化为 **+0.170%**（96小时），其中忽略了与 \( \Omega a^2 \) 成正比的常数项。

### 2.4 位涡守恒诊断

在无摩擦、绝热条件下，**Ertel位涡**沿流体质点守恒：

\[
\text{PV} = \frac{1}{\rho}(\boldsymbol{\zeta} + 2\boldsymbol{\Omega}) \cdot \nabla\theta
\]

**验证方法**：用拉格朗日方法追踪气块，检验其PV的沿轨迹变化。对于数值方案，**位涡的保持能力**是评价离散格式质量的关键指标。研究表明，有限体积方案在质量、示踪物和位涡守恒方面表现优异，而谱方法在能量守恒方面有天然优势。

### 2.5 熵与可逆性诊断

在绝热无摩擦条件下，**熵**应守恒。数值方案应保持：

\[
\frac{d}{dt}\int \rho s \, dV = 0
\]

**鲁棒不变量 vs 非鲁棒不变量**：**鲁棒不变量**（如质量、能量、角动量）在绝热无摩擦极限下守恒或近似守恒；**非鲁棒不变量**（如熵、位涡）在连续方程中守恒，但在数值离散中可能不守恒，因为存在从大尺度向小尺度的**级联过程**。对于非鲁棒不变量，模型性能的 satisfactory 要求**虚假源汇**远小于**真实物理源汇**。


## 三、第二层：动力学一致性检验

### 3.1 地转平衡检验

在自由大气中，风场应接近**地转风**：

\[
\mathbf{u}_g = \frac{1}{\rho f} \hat{\mathbf{k}} \times \nabla p
\]

**验证指标**：定义**地转偏差**：

\[
\text{AGD} = \frac{|\mathbf{u} - \mathbf{u}_g|}{|\mathbf{u}_g|}
\]

在中纬度自由大气中，AGD 应小于 **20%**。在赤道附近（\( f \to 0 \)），地转平衡失效，应改用**赤道Rossby波**关系检验。

**热成风平衡**：地转风随高度的变化与水平温度梯度有关：

\[
\frac{\partial \mathbf{u}_g}{\partial \ln p} = -\frac{R}{f} \hat{\mathbf{k}} \times \nabla T
\]

热成风关系是检验模型**垂直结构保真度**的核心工具。研究表明，对流层低层的地转风与热成风有较好的适应关系。

### 3.2 位涡与Rossby波检验

**Rossby波**的频散关系为：

\[
\omega = -\frac{\beta k}{k^2 + l^2 + f^2/(gH)}
\]

模型应能正确再现Rossby波的**相速度**和**群速度**。检验方法：在模型中初始化一个单一波数的Rossby波，追踪其传播和频散，与解析解对比。

### 3.3 能量级联检验

大气能量应从**大尺度向小尺度级联**，最终在耗散尺度被摩擦耗散。**动能谱**应遵循 **\( k^{-3} \) 和 \( k^{-5/3} \) 的幂律**：

\[
E(k) \propto \begin{cases}
k^{-3} & \text{大尺度（Enstrophy 级联）} \\
k^{-5/3} & \text{小尺度（能量级联）}
\end{cases}
\]

**验证方法**：计算模型输出的动能谱，与理论斜率对比。谱斜率的偏差反映数值耗散和参数化的质量。


## 四、第三层：地理与物理一致性

### 4.1 温度-降水-气压一致性

| 检验项 | 物理关系 | 可接受偏差 |
|--------|---------|-----------|
| 赤道低压带 | 温度高 → 气压低 | 气压最低点纬度与温度最高点纬度差 < 5° |
| 副热带高压带 | 下沉气流 → 干燥 | 降水最少区域与气压最高区域重合 |
| 副极地低压带 | 气旋活动 → 降水 | 降水峰值纬度与气压最低点纬度差 < 5° |
| 极地高压 | 温度低 → 气压高 | 气压最高点位于极地 |

### 4.2 风-气压-洋流一致性

**地转风检验**：在中纬度自由大气中，风应大致平行于等压线。**洋流检验**：Sverdrup平衡要求经向洋流由风应力旋度驱动。**Ekman抽吸**：正风应力旋度应驱动上升流，负旋度驱动下沉流。

### 4.3 水文循环一致性

**全球水量守恒**：

\[
\frac{d}{dt}\int (W + S + G) dV = 0
\]

其中 \( W \) 是大气水汽，\( S \) 是地表水（土壤水、湖泊、河流），\( G \) 是地下水。全球蒸发应等于全球降水：

\[
\int E \, dA = \int P \, dA
\]

**验证标准**：在长时间平均中，全球蒸发-降水差应小于 **1%**。

**径流-降水-蒸发一致性**：

\[
P = E + R + \Delta S
\]

其中 \( R \) 是径流，\( \Delta S \) 是储水量变化。在年尺度上，\( \Delta S \approx 0 \)，因此 \( P \approx E + R \)。

### 4.4 辐射-温度一致性

**行星能量平衡**：全球年平均吸收短波辐射应等于向外长波辐射：

\[
\frac{S_0}{4}(1 - \alpha_p) = \text{OLR}
\]

其中 \( \alpha_p \) 是行星反照率。**验证标准**：偏差应小于 **1%**。

**辐射-对流平衡**：在对流层中，**湿绝热递减率** \( \Gamma_m \approx 6.5 \, \text{K/km} \) 应与辐射冷却平衡。检验方法：计算模型输出的温度递减率，与理论值对比。


## 五、第四层：生态一致性

### 5.1 Köppen分类诊断

**Köppen-Geiger分类**是评价气候模型保真度的标准诊断工具。研究提出将Köppen分类作为**标准诊断量**，用于追踪气候模型的改进。

**评估方法**：将模型输出的月温度和月降水输入Köppen分类算法，得到气候类型图，与真实地球的Köppen图对比。**关键发现**：最先进的AOGCM在约 **20–30%** 的陆地区域（除南极外）无法捕获正确的Köppen带，且类似比例的次带被错误分配。

**降水误差主导**：在风暴解析模型中，**降水误差主导了气候分类错误**，温度偏差的作用次之，主要限于中纬度气候带边界。

### 5.2 生物群系一致性

| 生物群系 | 温度约束 | 降水约束 | 验证方法 |
|---------|---------|---------|---------|
| 热带雨林 | \( T_{\text{cold}} > 18°\text{C} \) | \( P > 2000 \, \text{mm} \) | 与ITCZ位置对比 |
| 沙漠 | \( \text{PET} > 2P \) | \( P < 250 \, \text{mm} \) | 与副热带高压带对比 |
| 北方针叶林 | \( \text{MAT} < 8°\text{C} \) | \( P > 300 \, \text{mm} \) | 与极地冷空气范围对比 |
| 苔原 | \( T_{\text{hot}} < 10°\text{C} \) | \( P > 100 \, \text{mm} \) | 与极地辐射对比 |

**多尺度一致性**：生物群系、土壤、农业类型在同一网格点上应逻辑一致。例如，如果生物群系是“沙漠”，土壤不应是“冲积土”，农业不应是“水稻”。

## 六、第五层：基准测试

### 6.1 Held-Suarez测试

**Held-Suarez测试**是大气动力学核心的标准基准。它用**牛顿松弛**替代完整物理参数化，产生一个理想化的“干大气”气候。**验证标准**：模型输出的**纬向平均温度**和**纬向风**应与参考解一致，偏差小于 **10%**。

### 6.2 Aquaplanet测试

**Aquaplanet测试**用**均匀水覆盖**的行星替代真实海陆分布，检验模型对**海气耦合**的模拟能力。**验证标准**：**ITCZ位置**、**Hadley环流强度**和**副热带急流位置**应与参考解一致。

### 6.3 地球参数下的完整验证

在地球参数下运行完整管线，与真实地球观测数据对比：

| 验证项 | 参考数据 | 可接受偏差 |
|--------|---------|-----------|
| 全球平均温度 | 14–15°C | ±2°C |
| 全球平均降水 | 1000 mm/年 | ±15% |
| 赤道-极地温差 | 40–50°C | ±5°C |
| 副热带沙漠位置 | 20°–30° | ±5° |
| ITCZ位置 | 0°–10°N | ±5° |

### 6.4 与ExoPlaSim的交叉验证

**ExoPlaSim**是基于PlaSim的中间复杂度GCM，T21分辨率、10层，一年气候积分在 **1分钟以内**完成。用ExoPlaSim在同一组行星参数下运行，将输出与本管线在粗分辨率下的结果做对比，是快速验证的有效途径。

import mlx.core as mx

def diagnose_energy_gpu(u, v, T, ps, z, lat):
    """MLX GPU: 全球能量积分"""
    KE = 0.5 * (u**2 + v**2)
    IE = c_v * T
    PE = g * z
    total = KE + IE + PE

    weight = mx.cos(lat)[:, None] * mx.ones_like(total)

### 7.3 Numba JIT加速

对于**逐网格的动力学一致性检验**（如地转偏差），用Numba编译：

```python
@njit(parallel=True, fastmath=True, cache=True)
def diagnose_geostrophic_deviation(u, v, p, lat, lon, R, Omega):
    """并行计算地转偏差"""
    nlat, nlon = u.shape
    agd = np.zeros((nlat, nlon))
    
    for i in prange(nlat):
        f = 2 * Omega * np.sin(lat[i])
        if abs(f) < 1e-6:
            continue  # 赤道附近跳过
        for j in range(nlon):
            # 气压梯度（中心差分）
            dp_dlon = (p[i, (j+1)%nlon] - p[i, (j-1)%nlon]) / (2 * R * np.cos(lat[i]))
            dp_dlat = (p[min(i+1,nlat-1), j] - p[max(i-1,0), j]) / (2 * R)
            
            # 地转风
            ug = -dp_dlat / (rho * f)
            vg = dp_dlon / (rho * f)
            
            # 地转偏差
            speed = np.sqrt(u[i,j]**2 + v[i,j]**2) + 1e-6
            agd[i,j] = np.sqrt((u[i,j]-ug)**2 + (v[i,j]-vg)**2) / speed
    
    return agd
```
