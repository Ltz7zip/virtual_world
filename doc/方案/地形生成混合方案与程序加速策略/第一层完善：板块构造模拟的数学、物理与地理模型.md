# 第一层完善：板块构造模拟的数学、物理与地理模型

## 一、球面板块划分：域扭曲 Voronoi 方案

### 1.1 为什么需要域扭曲

直接在球面上做 Voronoi 划分，得到的板块边界是球面测地线弧段——在视觉上过于几何化，缺乏真实板块边界的蜿蜒曲折感。解决方案是对输入坐标施加分形噪声扰动，再进行最近邻查询。Klisuaiji/earthengine 项目正是用**域扭曲球面 Voronoi** 取代了 WorldEngine 原有的 platec 模拟，先“生成微板块并归并为 6 大板块”。

### 1.2 球面均匀种子点生成

**Fibonacci 球面分布**是生成 N 个均匀分布球面点的标准方法：

```
φ_k = arccos(1 - 2k/(N-1)),  k = 0, 1, ..., N-1
θ_k = π(1 + √5) · k
```

转换为笛卡尔坐标后即为种子点。相比随机采样，Fibonacci 分布避免了极点聚集和局部空洞。

### 1.3 域扭曲

对每个网格单元的经纬度 `(λ, φ)` 施加噪声偏移：

```
λ' = λ + A_warp · n_1(λ, φ)
φ' = φ + A_warp · n_2(λ, φ)
```

其中 `n_1, n_2` 是两个独立的 fBm 噪声函数，`A_warp` 是扭曲幅度（典型值为板块平均角半径的 10%–20%）。然后在 `(λ', φ')` 上查询最近的种子点。这使板块边界变得蜿蜒曲折。

### 1.4 微板块归并

上一步得到 N 个微板块（N 取 200–500）。真实岩石圈板块的尺度分布不是均匀的——少量大板块占据了大部分面积。归并策略：

1. 随机选择 M 个（6–12）微板块作为“大板块核心”。
2. 对每个非核心微板块，计算其到大板块核心的**球面距离**和**共享边界弧长**。
3. 定义归并代价：`cost = α · dist + β / shared_length`，选择代价最小的核心归并。
4. 重复直到所有微板块归并完毕。

**关键约束**：归并后的大板块必须**在球面上连通**。如果归并产生碎片（不连通的子区域），需要将这些碎片重新分配给相邻板块。可以用图连通性检测（BFS/DFS）来验证。

### 1.5 SciPy 实现

```python
from scipy.spatial import SphericalVoronoi
import numpy as np

# 生成 Fibonacci 球面种子点
def fibonacci_sphere(n):
    i = np.arange(n)
    phi = np.arccos(1 - 2 * (i + 0.5) / n)
    theta = np.pi * (1 + np.sqrt(5)) * i
    return np.column_stack([
        np.sin(phi) * np.cos(theta),
        np.sin(phi) * np.sin(theta),
        np.cos(phi)
    ])

points = fibonacci_sphere(300)
sv = SphericalVoronoi(points, radius=1.0)
sv.sort_vertices_of_regions()
```

`SphericalVoronoi` 的内部算法是：计算输入点的凸包（等价于球面上的 Delaunay 三角剖分），然后用凸包邻接信息对每个生成点的 Voronoi 区域顶点排序。算法复杂度经验上为二次时间。对于 300–500 个种子点，计算时间在单次调用中完全可以接受。

**注意**：`SphericalVoronoi` 只处理**种子点**，不直接处理网格单元归属。网格单元的归属需要单独计算——用 `scipy.spatial.cKDTree` 在笛卡尔坐标中做最近邻查询，或者自行实现球面最近邻（用 `arccos` 计算角距离）。对于域扭曲版本，需要在扭曲后的坐标上查询，不能直接用 `SphericalVoronoi` 的 `regions` 属性。


## 二、板块运动学：欧拉极点与四元数

### 2.1 欧拉定理与球面刚体运动

欧拉定理指出：**刚体绕一个固定点的任意运动都可以表示为绕某一轴的旋转**。在球面上，这意味着任何岩石圈板块的运动都可以用一个**欧拉极点**（旋转轴与球面的交点）和一个**角速度**来描述。

板块上任意点 `P`（笛卡尔坐标向量）的速度为：

```
v = ω × P
```

其中 `ω = ω · ê` 是角速度矢量，`ê` 是指向欧拉极点的单位向量，`ω` 是角速度大小（rad/time）。这是板块运动学的基石。

### 2.2 相对速度计算

两个板块 A 和 B 之间的相对速度（在边界点 P 处）为：

```
v_rel = (ω_A - ω_B) × P = ω_R (ê_A × P) - ω_B (ê_B × P)
```

更紧凑地写成：

```
v_rel = ω_R × P
```

其中 `ω_R = ω_A - ω_B` 是相对角速度矢量，`ê_R = ω_R / |ω_R|` 是相对欧拉极点方向。

### 2.3 边界类型判定

在边界点 P 处，设 `n̂` 是边界的单位法向量（指向板块 A 的内部），相对速度 `v_rel` 与 `n̂` 的关系决定边界类型：

- **离散边界**（`v_rel · n̂ > 0`）：相对运动背离边界法向 → 张裂。形成洋中脊（海洋地壳）或裂谷（大陆地壳）。
- **汇聚边界**（`v_rel · n̂ < 0`）：相对运动指向边界法向 → 碰撞或俯冲。如果两侧都是大陆地壳，形成造山带；如果一侧是海洋地壳，发生俯冲，形成海沟和火山弧。
- **转换边界**（`|v_rel · n̂| ≈ 0` 且 `|v_rel × n̂| > 0`）：相对运动平行于边界 → 水平错动。

汇聚速率大小 `|v_rel|` 直接决定地壳增厚和造山带的强度。

### 2.4 四元数表示（推荐）

对于需要长时间积分（模拟数百万年板块漂移）的场景，**单位四元数**是比旋转矩阵更数值稳定的表示。2023 年 Schaeben 等人的工作系统建立了用四元数描述板块构造球面运动学的数学框架，核心公式：

对于绕单位轴 `ê` 旋转角度 `θ` 的旋转，四元数为：

```
q = cos(θ/2) + sin(θ/2) · ê
```

连续旋转通过四元数乘法实现：

```
q_total = q_n ∘ q_{n-1} ∘ ... ∘ q_1
```

角度和轴随时间的变化：`q(t) = cos(ω(t)/2) + sin(ω(t)/2) · ê`，其中 `ω(t)` 是累积旋转角度。瞬时角速度矢量为：

```
ω_vec = 2 q̇ ∘ q*
```

四元数的优势在于：没有万向节死锁（gimbal lock），旋转合成只需乘法（无需矩阵乘法），归一化简单，长时间积分时数值漂移远小于旋转矩阵。

### 2.5 板块角动量守恒

当两个板块碰撞并合并时，简单地让板块“停止”不符合物理。正确的做法是**角动量守恒**：

```
L_total = I_A · ω_A + I_B · ω_B = (I_A + I_B) · ω_merged
```

其中 `I_A, I_B` 是板块的转动惯量（对于球面板块，`I ∝ R^5 · 密度`），`ω_merged` 是合并后的角速度。碰撞过程中消耗的动能转化为地壳增厚的“势能预算”，这可以通过 `ΔE_kinetic = ½ I_A ω_A² + ½ I_B ω_B² - ½ (I_A+I_B) ω_merged²` 来估算，然后按比例分配到碰撞边界的地壳增厚上。


## 三、地壳均衡：Airy-Heiskanen 模型

### 3.1 物理原理

Airy 均衡模型的核心假设是：**密度均匀的地壳漂浮在密度更大的地幔上，达到流体静力平衡**。山脉有“山根”——地壳在山脉下方增厚，像冰山一样“浮”在地幔中。

设地壳正常厚度为 `T`（约 30 km），地壳密度 `ρ_c ≈ 2800 kg/m³`，地幔密度 `ρ_m ≈ 3300 kg/m³`。对于海拔为 `H` 的地表，山根厚度 `r` 满足：

```
r = (ρ_c / (ρ_m - ρ_c)) · H
```

这个关系是**线性**的：海拔越高，山根越深。对于 `ρ_c = 2800, ρ_m = 3300`，系数为 `2800/500 = 5.6`，即每上升 1 km 海拔，山根加深 5.6 km。

### 3.2 从地壳厚度到地表高程

反过来，如果我们知道地壳厚度 `C`（从地表到莫霍面），地表高程为：

```
H = ((ρ_m - ρ_c) / ρ_m) · (C - T)
```

其中 `T` 是参考地壳厚度（对应于海平面附近的高程）。这个公式是整个构造高程分配的核心——**地壳越厚，海拔越高**。碰撞带的厚地壳自然产生高山，洋中脊的薄地壳自然产生海底高地。

### 3.3 数值示例

| 构造环境 | 地壳厚度 C | 地表高程 H |
|---------|-----------|-----------|
| 正常大陆地壳 | 30 km | ≈ 0 m |
| 青藏高原 | 70 km | ≈ 4–5 km |
| 安第斯山脉 | 60 km | ≈ 3–4 km |
| 洋中脊 | 5–7 km | ≈ -2.5 km |
| 深海平原 | 7–10 km | ≈ -4 至 -5 km |

这些数值为参数校准提供了基准。


## 四、地壳增厚与造山：物理模型

### 4.1 汇聚速率驱动的增厚

在汇聚边界，地壳增厚速率与**汇聚速率**和**地壳缩短效率**成正比。一个实用的简化模型是：

```
dC/dt = η · |v_rel| · f(θ)
```

其中 `η` 是增厚效率系数（约 0.1–0.3），`|v_rel|` 是汇聚速率，`f(θ)` 是碰撞角度的修正因子（正面碰撞效率最高，斜碰撞部分能量转化为走滑运动）。

### 4.2 质量守恒约束

地壳增厚不能凭空产生质量。在碰撞带，地壳缩短量必须等于增厚量。设初始地壳长度为 `L_0`、厚度为 `C_0`，缩短后的长度为 `L`、厚度为 `C`，则：

```
L_0 · C_0 = L · C  →  C = C_0 · (L_0 / L)
```

缩短因子 `β = L_0 / L` 是造山带的关键参数。安第斯山脉中部的增厚因子 `β_0 = 2.34 ± 0.13`。喜马拉雅-青藏高原系统自 50 Ma 以来的增厚地壳体积约为 `(206–226) × 10^6 km³`。

### 4.3 造山带宽度与高度的比例关系

从两层 Newtonian 流体的力平衡分析可以推导出造山带的**高宽比**。垂直方向的力平衡给出均衡条件，水平方向的力平衡给出高宽比：

```
H_ridge / W_ridge ∝ (Δρ · g · C_0) / (η_eff · |v_rel|)
```

这意味着：**汇聚速率越快，造山带越窄越高**；地壳越厚，高宽比越大。这一关系在 Perazzo 和 Gratton 的分析中得到了系统推导。

### 4.4 时间积分与松弛

地壳增厚不是瞬时的。用显式时间积分：

```
C(t + Δt) = C(t) + η · |v_rel(t)| · Δt
```

但需要加入**重力松弛**项——当山根过深时，地幔的浮力会试图将地壳“推回”均衡状态：

```
dC/dt = η · |v_rel| - κ · (C - C_eq)
```

其中 `C_eq` 是当前高程对应的均衡地壳厚度，`κ` 是松弛速率（时间尺度约 10–50 Ma）。这保证了长时间积分后系统不会无限制地增厚。


## 五、俯冲带与海沟模型

### 5.1 海沟深度

俯冲带的海沟深度由**俯冲板片年龄**和**俯冲速率**共同决定。一个简化的经验关系：

```
D_trench ≈ -8000 - 2000 · log10(Age_plate / 10)
```

其中 `Age_plate` 是俯冲板片的年龄（Ma）。年轻的板片（< 20 Ma）俯冲时，海沟较浅（-4000 至 -6000 m）；古老的板片（> 100 Ma）俯冲时，海沟更深（-8000 至 -11000 m）。这是因为老板片更冷、密度更大，负浮力更强。

### 5.2 火山弧位置

俯冲板片在约 100–150 km 深度发生脱水，触发地幔楔部分熔融，形成火山弧。火山弧距离海沟的水平距离约为 `d_arc ≈ 100–200 km`（取决于俯冲角度）。在模型中，火山弧表现为海沟内侧的一条高程隆起带（+ 1000 至 + 3000 m），叠加在俯冲板片的地形之上。


## 六、加速方案：针对板块构造模拟

### 6.1 热点识别

板块构造模拟中，计算热点是**边界类型判定**和**地壳增厚迭代**——这两个过程都需要在每个时间步遍历所有网格单元，计算相对速度、判定边界类型、更新地壳厚度。

### 6.2 向量化第一步

在 Numba 之前，先用 NumPy 矢量化消灭 Python 循环。边界类型判定的核心计算是向量化的叉积和点积：

```python
# 所有边界点的相对速度（向量化）
v_rel = np.cross(omega_rel, P_boundary)  # shape: (n_boundary, 3)

# 与边界法向的点积
dot_products = np.einsum('ij,ij->i', v_rel, n_boundary)

# 边界类型判定
divergent = dot_products > threshold
convergent = dot_products < -threshold
transform = np.abs(dot_products) <= threshold
```

对于地壳增厚的时间积分，每步都是向量化的：

```python
# 所有汇聚边界的增厚（向量化）
convergent_mask = (dot_products < -threshold)
crust_thickness[convergent_mask] += eta * convergence_rate[convergent_mask] * dt
```

### 6.3 Numba JIT 加速

对于时间积分循环（可能数千步），将整个循环放在一个 `@njit` 函数内部，避免在 Python 层反复调用。对于地壳增厚的迭代：

```python
@njit(parallel=True, fastmath=True, cache=True)
def integrate_crust_thickness(crust_thickness, convergence_rate, mask, eta, dt, n_steps):
    for step in range(n_steps):
        for i in prange(crust_thickness.shape[0]):
            if mask[i]:
                crust_thickness[i] += eta * convergence_rate[i] * dt
        # 重力松弛（同样并行）
        for i in prange(crust_thickness.shape[0]):
            crust_thickness[i] -= kappa * (crust_thickness[i] - C_eq[i]) * dt
    return crust_thickness
```

`parallel=True` 启用自动并行化，`prange` 显式指定并行循环，`cache=True` 缓存编译结果避免重复编译。地幔流动地球动力学代码的经验表明，Numba JIT 编译在矩阵组装和粒子网格计算中分别实现了 **30× 和 258×** 的加速。

### 6.4 JAX 用于长时间积分

如果模拟时间尺度达到数百万年、需要数千个时间步，JAX 的 `jit` 和 `vmap` 可以提供额外的加速，并且支持 GPU：

```python
import jax.numpy as jnp
from jax import jit, vmap

@jit
def step(crust, omega_rel, P, n_boundary, eta, dt):
    v_rel = jnp.cross(omega_rel, P)
    dots = jnp.einsum('ij,ij->i', v_rel, n_boundary)
    mask = dots < -0.01
    crust = crust + eta * jnp.where(mask, jnp.abs(dots), 0.0) * dt
    return crust

# 用 lax.scan 做时间积分
from jax import lax
final_crust, _ = lax.scan(lambda c, _: (step(c, ...), None), 
                           initial_crust, None, length=n_steps)
```

JAX 的 `lax.scan` 将循环展开为 XLA 计算图，避免了 Python 循环开销，GPU 上可达到极高的吞吐量。

### 6.5 加速分工建议

| 模块 | 推荐工具 | 预期加速 |
|------|---------|---------|
| 球面 Voronoi 种子点生成 | NumPy（Fibonacci 公式） | 已足够快 |
| 域扭曲 + 最近邻查询 | SciPy cKDTree | 已足够快 |
| 边界类型判定（单次） | NumPy 向量化 | 10–50× vs Python 循环 |
| 地壳厚度时间积分 | Numba `@njit(parallel=True)` | 额外 10–30× |
| 长时间积分（>1000 步） | JAX `jit` + `lax.scan` | GPU 上 50–100× |
| 多个世界并行 | joblib `Parallel` | 线性加速 |


## 七、完整板块构造模拟的伪代码管线

```
1. 生成 N 个 Fibonacci 球面种子点
2. 域扭曲：对每个种子点和网格坐标施加 fBm 噪声偏移
3. 球面最近邻查询：每个网格单元归属到最近的扭曲种子点
4. 微板块归并：将 N 个微板块归并为 6–12 个大板块
5. 为大板块分配欧拉极点 (ê) 和角速度 (ω)
6. 计算相邻板块的边界单元和边界法向
7. 对每个边界点计算相对速度 v_rel = (ω_A - ω_B) × P
8. 根据 v_rel · n̂ 判定边界类型（离散/汇聚/转换）
9. 初始化地壳厚度场 C = T（正常厚度）
10. 时间积分循环 t = 0 → T_total：
    a. 对汇聚边界，C += η · |v_rel| · Δt
    b. 对离散边界，C -= δ · |v_rel| · Δt（地壳减薄）
    c. 重力松弛：C -= κ · (C - C_eq) · Δt
    d. 如果板块碰撞合并，用角动量守恒更新 ω
11. 用 Airy 均衡公式将地壳厚度转换为地表高程：H = ((ρ_m-ρ_c)/ρ_m) · (C - T)
12. 对俯冲带单独处理：叠加海沟深度和火山弧隆起
```

这个管线产出的构造高程场，就是后续噪声精修和侵蚀模拟的输入。
