# 总体建模哲学：分层复杂度与因果链

## 一、建模哲学的核心原则

气候系统模拟的严谨性不取决于单一方程组的完整程度，而取决于**模型复杂度与待解问题之间的匹配程度**。一个在 1° 分辨率下求解完整原始方程组的模型，如果 Spin-Up 时间不足或参数化方案不适用于虚拟行星，其输出可能远不如一个精心设计的纬向平均能量平衡模型可靠。

本项目的建模哲学建立在三条原则之上：

**第一条：分层复杂度（Hierarchy of Complexity）** 。气候系统包含从行星尺度（10⁴ km）到湍流尺度（10⁻³ km）的连续谱。没有任何单一模型能同时解析所有尺度。正确的做法是建立**多个复杂度层级**，每个层级解析特定尺度范围的现象，层与层之间通过**限制算子**（restriction）和**延长算子**（prolongation）衔接。这与多重网格方法的思想同源：粗网格捕获大尺度结构，细网格捕获局部细节，两者通过插值算子耦合。

**第二条：因果链闭合（Causal Chain Closure）** 。气候系统的各变量之间存在明确的因果依赖关系。一个物理上自洽的模型必须保证因果链的**完整性和闭合性**：如果 A 影响 B，则 B 对 A 的反馈必须被显式建模或被证明可忽略。例如，温度影响风场，风场影响洋流，洋流影响温度——这个三元环必须闭合，否则系统会漂移到非物理状态。

**第三条：守恒律优先（Conservation First）** 。在任何数值离散化之前，必须明确模型保留哪些守恒律。对于气候系统，核心守恒律包括：

- **能量守恒**：\( \frac{d}{dt}\int (c_p T + L_v q + \Phi) dm = \text{净辐射输入} \)
- **质量守恒**：\( \frac{d}{dt}\int \rho \, dV = 0 \)（干空气、水、盐分分别守恒）
- **角动量守恒**：\( \frac{d}{dt}\int (\Omega R^2 \cos^2\phi + u R \cos\phi) dm = \text{力矩} \)
- **涡度守恒**：在无摩擦、正压条件下，位涡 \( q = (\zeta + f)/h \) 沿流体质点守恒

数值方案必须至少保留能量和质量守恒；角动量和涡度守恒在特定近似下保留。


## 二、分层复杂度的数学定义

### 2.1 复杂度层级的严格定义

定义气候模型的复杂度层级 \( \mathcal{L}_k \)（\( k = 0, 1, 2, 3 \)）为一个五元组：

\[
\mathcal{L}_k = \left( \mathcal{V}_k, \mathcal{E}_k, \mathcal{D}_k, \mathcal{N}_k, \mathcal{C}_k \right)
\]

其中：

- \( \mathcal{V}_k \)：**状态变量集**。层级 \( k \) 所显式预测的物理量集合。
- \( \mathcal{E}_k \)：**演化方程集**。描述 \( \mathcal{V}_k \) 随时间演化的微分方程组。
- \( \mathcal{D}_k \)：**诊断关系集**。从 \( \mathcal{V}_k \) 直接导出的物理量（不参与时间积分）。
- \( \mathcal{N}_k \)：**数值方法集**。空间离散化、时间积分、求解器。
- \( \mathcal{C}_k \)：**闭合假设集**。对未解析尺度过程的参数化方案。

层与层之间的关系由**限制算子** \( \mathcal{R}_{k \to k-1} \)（从细到粗）和**延长算子** \( \mathcal{P}_{k-1 \to k} \)（从粗到细）定义。

### 2.2 层级 0：行星能量平衡（0D/1D EBM）

**状态变量**：\( \mathcal{V}_0 = \{ T(\phi, t) \} \)，纬向平均地表温度。

**演化方程**：

\[
C(\phi) \frac{\partial T}{\partial t} = S(\phi)(1 - \alpha(\phi, T)) - \text{OLR}(T) + \frac{\partial}{\partial \phi}\left[ D(\phi) \cos\phi \frac{\partial T}{\partial \phi} \right]
\]

**诊断关系**：\( \text{OLR} = A + B T \)，\( \alpha = \alpha_0 + \alpha_{\text{ice}}(T) \)。

**闭合假设**：经向热输运由扩散参数化 \( D(\phi) \) 表示，不解析大气环流。

**适用范围**：行星尺度（10⁴ km），时间尺度 > 10⁵ s（约 1 天）。捕获全球温度分布、冰-反照率反馈、雪球状态。

**计算成本**：\( O(N_\phi) \) 每时间步，其中 \( N_\phi \) 是纬度格点数（通常 50–200）。单次 Spin-Up 仅需几秒。

### 2.3 层级 1：纬向平均环流（2D 纬向平均模型）

**状态变量**：\( \mathcal{V}_1 = \{ T(\phi, p, t), u(\phi, p, t), v(\phi, p, t), q(\phi, p, t) \} \)。

**演化方程**（纬向平均原始方程）：

\[
\frac{\partial \bar{u}}{\partial t} = f \bar{v} - \bar{v} \frac{\partial \bar{u}}{\partial \phi} \cdot \frac{1}{R} - \bar{\omega} \frac{\partial \bar{u}}{\partial p} + \bar{\mathcal{F}}_u
\]

\[
\frac{\partial \bar{T}}{\partial t} = -\frac{\bar{v}}{R} \frac{\partial \bar{T}}{\partial \phi} - \bar{\omega} \frac{\partial \bar{T}}{\partial p} + \frac{\bar{Q}}{c_p} + \bar{\mathcal{F}}_T
\]

\[
\frac{\partial \bar{q}}{\partial t} = -\frac{\bar{v}}{R} \frac{\partial \bar{q}}{\partial \phi} - \bar{\omega} \frac{\partial \bar{q}}{\partial p} + \bar{E} - \bar{P}
\]

**诊断关系**：纬向平均经向环流 \( (\bar{v}, \bar{\omega}) \) 由**Eliassen-Palm 通量**和**热力直接环流**的平衡确定。位势高度由静力学方程 \( \partial \bar{\Phi}/\partial \ln p = -R \bar{T} \) 给出。

**闭合假设**：涡旋通量 \( \overline{u'v'} \) 和 \( \overline{v'T'} \) 由**混合长理论**参数化。

**适用范围**：行星尺度到天气尺度（10³–10⁴ km），时间尺度 > 10⁴ s（约 3 小时）。捕获 Hadley 环流、Ferrel 环流、急流位置、副热带高压带。

**计算成本**：\( O(N_\phi \cdot N_p) \) 每时间步，典型 100×20 = 2000 格点。比层级 0 高约 2 个数量级。

### 2.4 层级 2：中间复杂度大气（浅水/原始方程，2.5D）

**状态变量**：\( \mathcal{V}_2 = \{ \mathbf{u}(\lambda, \phi, t), h(\lambda, \phi, t), q(\lambda, \phi, t) \} \)，其中 \( \mathbf{u} \) 是水平速度，\( h \) 是等效深度（与位温相关）。

**演化方程**（球面浅水方程）：

\[
\frac{\partial \mathbf{u}}{\partial t} + (\mathbf{u} \cdot \nabla)\mathbf{u} + f \hat{\mathbf{k}} \times \mathbf{u} = -g \nabla h + \mathcal{D}_u
\]

\[
\frac{\partial h}{\partial t} + \nabla \cdot (h \mathbf{u}) = \hat{Q} - \mathcal{D}_h
\]

\[
\frac{\partial q}{\partial t} + \nabla \cdot (q \mathbf{u}) = E - P
\]

**诊断关系**：气压场由 \( p = p_0 + \rho_0 g h \) 给出，风应力由 \( \boldsymbol{\tau} = \rho_{\text{air}} C_D |\mathbf{u}| \mathbf{u} \) 给出。

**闭合假设**：辐射、对流、边界层过程通过 \( \hat{Q} \) 和 \( \mathcal{D} \) 参数化。

**适用范围**：天气尺度到行星尺度（10²–10⁴ km），时间尺度 > 10³ s（约 17 分钟）。捕获 Rossby 波、斜压不稳定、锋面、季风。

**计算成本**：\( O(N_\lambda \cdot N_\phi) \) 每时间步，1° 分辨率下约 65,000 格点。比层级 1 高约 1–2 个数量级。

### 2.5 层级 3：区域高分辨率（3D 原始方程）

**状态变量**：\( \mathcal{V}_3 = \{ \mathbf{u}(\lambda, \phi, \sigma, t), T, q, p_s \} \)。

**演化方程**：完整的原始方程组（前述第 5.1 节）。

**适用范围**：中尺度到天气尺度（10–10³ km），时间尺度 > 10² s。捕获地形波、海陆风、城市热岛。

**计算成本**：\( O(N_\lambda \cdot N_\phi \cdot N_\sigma) \)，1° 分辨率 + 20 层约 1.3×10⁶ 格点。比层级 2 高约 1–2 个数量级。

### 2.6 层级选择的决策准则

对于虚拟世界生成器，推荐**层级 0 → 层级 1 → 层级 2** 的渐进式管线：

| 阶段 | 层级 | 目的 | 输出 |
|------|------|------|------|
| 快速约束 | L0 | 确定全球温度范围、冰盖范围 | 全球温度分布、冰盖掩码 |
| 主气候场 | L1 | 确定气压带、风带、降水带 | 一月/七月温度、气压、风、降水 |
| 区域细节 | L2 | 细化季风、洋流、地形效应 | 高分辨率风场、洋流场 |

层级 3 仅在用户请求特定区域的高分辨率细节时启用。


## 三、因果链的数学形式

### 3.1 因果链的有向图表示

气候系统可以表示为一个**有向图** \( \mathcal{G} = (\mathcal{V}, \mathcal{E}) \)，其中节点 \( \mathcal{V} \) 是物理量，边 \( \mathcal{E} \) 是因果关系。每条边携带一个**传递函数** \( \mathcal{T}_{i \to j} \)，描述 \( i \) 对 \( j \) 的影响。

核心因果链为：

```
太阳辐射 → 温度 → 气压 → 风 → 风应力 → 洋流 → 温度（反馈）
                ↓                ↓
              蒸发 → 水汽 → 降水 → 潜热释放 → 温度（反馈）
                ↓
              径流 → 土壤湿度 → 蒸发（反馈）
```

### 3.2 因果链的微分方程形式

因果链的每一个环节都可以用微分方程严格表述：

**环节 1：辐射 → 温度**

\[
C \frac{\partial T}{\partial t} = \mathcal{R}_{\text{net}}(T, \alpha) = S(1-\alpha) - \text{OLR}(T)
\]

**环节 2：温度 → 气压**

由静力学平衡和理想气体定律：

\[
\frac{\partial p}{\partial z} = -\rho g, \quad p = \rho R T
\]

积分得：

\[
p(z) = p_0 \exp\left( -\int_0^z \frac{g}{R T(z')} dz' \right)
\]

**环节 3：气压 → 风**

由水平动量方程，忽略加速度和摩擦：

\[
f \hat{\mathbf{k}} \times \mathbf{u}_g = -\frac{1}{\rho} \nabla p
\]

地转风为：

\[
\mathbf{u}_g = \frac{1}{\rho f} \hat{\mathbf{k}} \times \nabla p
\]

**环节 4：风 → 风应力**

\[
\boldsymbol{\tau} = \rho_{\text{air}} C_D |\mathbf{u}| \mathbf{u}
\]

**环节 5：风应力 → 洋流**

由 Sverdrup 平衡：

\[
\beta v = \frac{1}{\rho_0} \hat{\mathbf{k}} \cdot (\nabla \times \boldsymbol{\tau})
\]

**环节 6：洋流 → 温度**

\[
\frac{\partial T}{\partial t} + \mathbf{u}_{\text{oc}} \cdot \nabla T = \kappa \nabla^2 T + \frac{Q_{\text{air-sea}}}{\rho_0 c_p H}
\]

### 3.3 因果链的闭合性检验

因果链闭合的数学条件是：**图中每个环路的增益乘积小于 1**（稳定条件），或环路增益恰好为 1（中性），或大于 1 但被非线性饱和机制限制（振荡）。

例如，冰-反照率反馈环：

\[
\Delta T \xrightarrow{\partial \alpha/\partial T} \Delta \alpha \xrightarrow{\partial S_{\text{abs}}/\partial \alpha} \Delta S_{\text{abs}} \xrightarrow{\partial T/\partial S_{\text{abs}}} \Delta T
\]

环路增益为：

\[
G_{\text{ice}} = \frac{\partial T}{\partial S_{\text{abs}}} \cdot \frac{\partial S_{\text{abs}}}{\partial \alpha} \cdot \frac{\partial \alpha}{\partial T} = \frac{1}{B} \cdot (-S) \cdot \frac{\partial \alpha}{\partial T}
\]

当 \( G_{\text{ice}} > 1 \) 时，系统进入不稳定，可能触发雪球状态。这是虚拟行星气候需要检测的关键非线性行为。

### 3.4 因果链的时间尺度分离

气候系统中不同因果环节的时间尺度差异巨大：

| 环节 | 时间尺度 | 数学特征 |
|------|---------|---------|
| 辐射平衡 | 10⁵–10⁶ s（天） | 快，可诊断 |
| 大气平流 | 10⁴–10⁵ s（小时） | 中，需时间积分 |
| 边界层混合 | 10³ s（分钟） | 快，参数化 |
| 海洋混合层 | 10⁶–10⁷ s（月） | 慢，需时间积分 |
| 深海环流 | 10⁹–10¹⁰ s（千年） | 极慢，可诊断或稳态 |
| 冰盖演化 | 10¹¹–10¹³ s（万年） | 地质尺度，可固定 |

**时间尺度分离定理**：如果快过程的时间尺度远小于慢过程，则快过程可以视为**诊断平衡**（瞬时调整），不需要时间积分。例如，辐射平衡的时间尺度（天）远小于海洋混合层（月），因此温度场可以用辐射平衡诊断，而海洋温度需要时间积分。

这个定理是本项目分层策略的数学基础：**每个层级只对其特征时间尺度内的过程做时间积分，更快的诊断，更慢的固定或稳态求解**。


## 四、各层级的物理模型

### 4.1 层级 0 的物理模型

层级 0 的核心物理是**行星辐射平衡**。物理上，它假设：

1. 大气对短波辐射透明（或均匀吸收），对长波辐射不透明（温室效应）。
2. 经向热输运由扩散过程主导。
3. 温度场达到辐射-对流平衡。

这些假设在行星尺度上成立，但在区域尺度上失效（忽略了海洋热输运、云反馈、气溶胶）。

**物理约束**：
- 全球能量守恒：\( \int S(1-\alpha) dA = \int \text{OLR} \, dA \)
- 极地-赤道温度差必须为正：\( T_{\text{eq}} > T_{\text{pole}} \)
- 冰盖范围由 \( T = T_{\text{freeze}} \) 等值线确定

### 4.2 层级 1 的物理模型

层级 1 引入了**纬向平均环流**。物理上，它假设：

1. 纬向对称性：所有变量在经度方向平均。
2. 涡旋通量由混合长理论参数化。
3. 经向环流由热力直接环流和 Eliassen-Palm 通量平衡确定。

**物理约束**：
- 角动量守恒：Hadley 环流的上支必须满足 \( M = \Omega R^2 \cos^2\phi + u R \cos\phi \) 守恒
- 热成风平衡：\( \frac{\partial \bar{u}}{\partial p} = \frac{R}{f p} \frac{\partial \bar{T}}{\partial \phi} \)
- 质量守恒：\( \int \bar{v} \cos\phi \, dp = 0 \)

### 4.3 层级 2 的物理模型

层级 2 引入**水平非对称性**。物理上，它假设：

1. 大气是浅层流体，水平尺度 >> 垂直尺度。
2. 静力学平衡成立。
3. 垂直结构由少数模态（斜压模）表示。

**物理约束**：
- 位涡守恒（无摩擦）：\( \frac{D}{Dt}\left( \frac{\zeta + f}{h} \right) = 0 \)
- 能量守恒：\( \frac{d}{dt}\int \left( \frac{1}{2} h |\mathbf{u}|^2 + \frac{1}{2} g h^2 \right) dA = \text{强迫} \)
- 质量守恒：\( \frac{d}{dt}\int h \, dA = \text{源汇} \)

### 4.4 层级 3 的物理模型

层级 3 是完整的原始方程组。物理上，它保留所有对天气和气候重要的过程，但滤除声波（通过静力学近似）和重力波的高频振荡（通过半隐式积分）。

**物理约束**：完整的能量、质量、角动量、涡度守恒。


## 五、地理约束的数学形式

### 5.1 球面几何约束

所有方程必须在球面上表述。关键几何量：

**球面梯度**：

\[
\nabla f = \frac{1}{R \cos\phi} \frac{\partial f}{\partial \lambda} \hat{\boldsymbol{\lambda}} + \frac{1}{R} \frac{\partial f}{\partial \phi} \hat{\boldsymbol{\phi}}
\]

**球面散度**：

\[
\nabla \cdot \mathbf{u} = \frac{1}{R \cos\phi} \left[ \frac{\partial u}{\partial \lambda} + \frac{\partial (v \cos\phi)}{\partial \phi} \right]
\]

**球面旋度**：

\[
\nabla \times \mathbf{u} = \frac{1}{R \cos\phi} \left[ \frac{\partial v}{\partial \lambda} - \frac{\partial (u \cos\phi)}{\partial \phi} \right]
\]

**科里奥利参数**：

\[
f = 2 \Omega \sin\phi
\]

**β 参数**：

\[
\beta = \frac{df}{d\phi} \cdot \frac{1}{R} = \frac{2\Omega \cos\phi}{R}
\]

### 5.2 海陆分布约束

海陆分布通过**热容量差异**和**表面粗糙度差异**影响气候：

**热容量**：
\[
C(\lambda, \phi) = \begin{cases} C_{\text{land}} & \text{陆地} \\ C_{\text{ocean}} \cdot H_{\text{mix}} & \text{海洋} \end{cases}
\]

**表面粗糙度**：

\[
z_0(\lambda, \phi) = \begin{cases} 0.1 \, \text{m} & \text{陆地} \\ 10^{-4} \, \text{m} & \text{海洋} \end{cases}
\]

**反照率**：

\[
\alpha(\lambda, \phi) = \begin{cases} \alpha_{\text{land}} & \text{陆地} \\ \alpha_{\text{ocean}} & \text{海洋} \\ \alpha_{\text{ice}} & \text{冰盖} \end{cases}
\]

### 5.3 地形约束

地形通过以下机制影响气候：

**地形抬升**：气流遇到山脉被迫抬升，产生绝热冷却和凝结。垂直速度：

\[
w_{\text{oro}} = \mathbf{u} \cdot \nabla h
\]

**地形波**：气流翻越山脉产生重力波，动量通量为：

\[
\tau_{\text{wave}} = \rho_0 N \kappa U h^2
\]

其中 \( N \) 是 Brunt-Väisälä 频率，\( \kappa \) 是水平波数，\( U \) 是风速。

**阻塞效应**：当 \( N h / U > 1 \) 时，气流被阻塞，形成背风坡的停滞区。

### 5.4 纬度约束

纬度的几何约束导致：

**经线收敛**：\( \Delta x = R \cos\phi \cdot \Delta\lambda \)。在高纬度，相同的经度间隔对应更小的物理距离。

**科里奥利力**：\( f \to 0 \) 在赤道，\( f \to \pm 2\Omega \) 在极地。

**太阳辐射**：\( S \propto \cos\phi \) 在年平均意义下。

这些约束导致气候带的存在：赤道辐合带、副热带高压、副极地低压、极地高压。


## 六、层间耦合：限制算子与延长算子

### 6.1 限制算子（粗化）

从层级 \( k \) 到 \( k-1 \) 的限制算子 \( \mathcal{R}_{k \to k-1} \) 将细网格数据平均到粗网格：

\[
\bar{T}_{i,j}^{(k-1)} = \frac{\sum_{m,n \in \text{cell}(i,j)} T_{m,n}^{(k)} \cdot A_{m,n}}{\sum_{m,n} A_{m,n}}
\]

其中 \( A_{m,n} \) 是细网格单元面积。面积加权平均保证了物理量的守恒性。

### 6.2 延长算子（细化）

从层级 \( k-1 \) 到 \( k \) 的延长算子 \( \mathcal{P}_{k-1 \to k} \) 将粗网格数据插值到细网格。使用**保守插值**：

\[
T_{m,n}^{(k)} = T_{i,j}^{(k-1)} + \Delta T_{\text{detail}}(m,n)
\]

其中 \( \Delta T_{\text{detail}} \) 是细网格的细节项，通常由更高分辨率的过程（如地形）诊断得到。

### 6.3 耦合的一致性条件

层间耦合必须满足**一致性条件**：粗网格上的物理量必须等于细网格的适当平均。

\[
\mathcal{R}_{k \to k-1} \circ \mathcal{P}_{k-1 \to k} = \mathcal{I}
\]

即先细化再粗化应恢复原值。这在数值上要求限制算子和延长算子互为伴随。

### 6.4 双向反馈接口

每个层级提供**上行接口**和**下行接口**：

**上行接口**（细 → 粗）：将细网格的统计量传递给粗网格。例如，层级 2 的涡旋通量 \( \overline{u'v'} \) 传递给层级 1 作为参数化输入。

**下行接口**（粗 → 细）：将粗网格的边界条件传递给细网格。例如，层级 1 的纬向平均温度场传递给层级 2 作为热力强迫。


## 七、加速方案：分层策略

### 7.1 分层加速的核心思想

不同层级的计算成本差异巨大，因此加速策略必须**按层级定制**：

| 层级 | 计算成本 | 瓶颈 | 加速策略 |
|------|---------|------|---------|
| L0 | 极低 | 无 | 无需加速，直接 NumPy |
| L1 | 低 | 参数化方案 | Numba JIT |
| L2 | 中 | 时间积分 | JAX `lax.scan` + GPU |
| L3 | 高 | 3D 求解器 | MPI + GPU |

### 7.2 层级 0 的加速

层级 0 的计算量极小（通常 < 1000 格点），**不需要任何加速**。用纯 NumPy 即可，单次 Spin-Up 在毫秒级完成。

### 7.3 层级 1 的加速

### 7.4 层级 2 的加速

层级 2 的核心是**时间积分**。用 JAX 的 `lax.scan` 将整个时间循环编译为 XLA 计算图：

```python
@jit
def shallow_water_step(state, params):
    u, v, h, q = state
    # 向量化 stencil 计算
    du = -jnp.einsum('ij,ij->ij', u, grad_lon(h)) + params.f * v
    dv = -jnp.einsum('ij,ij->ij', v, grad_lat(h)) - params.f * u
    dh = -div(u*h, v*h)
    dq = -div(u*q, v*q) + params.E - params.P
    return (u + du*params.dt, v + dv*params.dt, 
            h + dh*params.dt, q + dq*params.dt)

def integrate(state, n_steps):
    return lax.scan(shallow_water_step, state, None, length=n_steps)
```

GPU 上预期加速 50–100× 相对于单 CPU。

### 7.5 层级 3 的加速

层级 3 需要**域分解 + MPI**。按纬度带分解，每个进程负责一个纬度带，边界处交换数据：

```python
from mpi4py import MPI
comm = MPI.COMM_WORLD
rank = comm.Get_rank()
size = comm.Get_size()

# 每个进程负责的纬度范围
lat_start = rank * nlat // size
lat_end = (rank + 1) * nlat // size

# 边界交换
if rank > 0:
    comm.Sendrecv(sendbuf=u[lat_start], dest=rank-1, 
                  recvbuf=u[lat_start-1], source=rank-1)
```

GPU 上每个进程再叠加 JAX 加速。

### 7.6 层间耦合的加速

层间耦合的瓶颈在**插值**。限制算子和延长算子用 JAX 的 `jnp.interp` 或 `jax.image.resize` 实现，在 GPU 上批量执行。

```python
from jax.image import resize

# 粗化：面积加权平均
def restrict(fine, shape):
    return resize(fine, shape, method='linear', antialias=True)

# 细化：双线性插值
def prolong(coarse, shape):
    return resize(coarse, shape, method='linear')
```


## 八、完整的分层因果链管线

```
输入：行星参数 (Ω, ε, S₀, 大气成分), 地形 H, 海陆掩码

=== 层级 0：行星能量平衡 ===
1. 计算 S_TOA(φ) 对一月和七月
2. 初始化 T₀(φ)
3. Spin-Up EBM 至平衡
4. 输出：T_global(φ), 冰盖掩码, OLR

=== 层级 1：纬向平均环流 ===
5. 以 T_global 为强迫，积分纬向平均原始方程
6. 参数化涡旋通量
7. 输出：T(φ,p), u(φ,p), v(φ,p), q(φ,p), 气压带, 风带

=== 层级 2：中间复杂度大气 ===
8. 以层级 1 输出为强迫，积分球面浅水方程
9. 加入海陆热力差异和地形强迫
10. 输出：一月/七月 u(λ,φ), v(λ,φ), h(λ,φ), 气压场

=== 海洋模块 ===
11. 从风场计算风应力 τ
12. 求解 Sverdrup 平衡 + 西边界层
13. 加入热盐环流
14. 输出：洋流场, 海表温度

=== 海气耦合 ===
15. 洋流温度反馈到大气温度场
16. 迭代步骤 8-15 直至收敛

=== 水循环 ===
17. 蒸发：E = ρ C_E |u| (q_s - q)
18. 水汽输送：∂q/∂t + ∇·(qu) = E - P
19. 对流降水：P_conv = CAPE/τ
20. 地形降水：P_oro = ρ q max(u·∇h, 0)
21. 大尺度降水：P_ls = 饱和凝结
22. 输出：降水场, 蒸发场

=== 气候分类 ===
23. Köppen 分类：基于月均温和月降水
24. 输出：气候类型图
```

这个管线的每一步都遵循分层复杂度原则：**在正确的尺度上使用正确的物理**。层级 0 确定全局约束，层级 1 建立纬向结构，层级 2 引入水平非对称性，海洋模块处理慢过程，水循环处理快过程。每个模块的输出都通过限制/延长算子与相邻模块耦合，保证了因果链的完整性和闭合性。
