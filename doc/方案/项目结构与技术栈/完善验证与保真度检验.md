# 完善验证与保真度检验

## 一、总体架构：八层验证体系

验证与保真度是虚拟世界生成器的**质量保证层**。它需要在多个尺度、多个物理量上系统地检验生成结果的**物理自洽性、数值正确性和地理合理性**。本模块采用八层验证架构：

**第一层：守恒律诊断**。检验能量、质量、角动量、位涡等物理量的守恒性。

**第二层：动力学一致性检验**。检验地转平衡、热成风平衡、位涡守恒等动力学关系。

**第三层：辐射-能量一致性**。检验行星能量平衡、辐射-对流平衡。

**第四层：水循环一致性**。检验蒸发-降水-径流的闭合性。

**第五层：海洋环流一致性**。检验Sverdrup平衡、Ekman抽吸。

**第六层：生态一致性**。检验Köppen分布、生物群系、土壤、农业的逻辑一致性。

**第七层：基准测试**。Held-Suarez、Aquaplanet等标准基准。

**第八层：地球对比**。在地球参数下与真实观测数据对比。

在MacBook Pro 2024上，核心验证用**MLX GPU**加速全球积分和分类判定，用**Numba JIT**加速逐网格的动力学一致性检验，验证结果用**Zarr**缓存。


## 二、第一层：守恒律诊断

### 2.1 能量守恒诊断

大气总能量（动能 + 内能 + 位能）的守恒方程为：

\[
\frac{d}{dt}\int \rho \left( \frac{|\mathbf{u}|^2}{2} + c_v T + \Phi \right) dV = \text{净辐射输入} + \text{表面通量}
\]

在谱空间中，能量积分可表达为：

\[
\text{Energy/Unit mass} = \frac{a^2}{\sqrt{2}p_0^0}\int \sum_{m=-J}^{+J}\sum_{l=|m|}^{|m|+J} p_l^{m*}\left\{E_l^m + \Phi_l^m + \frac{c_v}{a^2} T_l^m\right\} \partial\sigma
\]

其中 \( p_l^m \) 是表面气压的谱系数。**验证标准**：在无辐射强迫的绝热积分中，全球总能量的漂移率应小于 **0.1%/天**。历史谱模型的实测数据表明，96小时积分中总能量变化约 **-0.013%**，角动量变化约 **+0.170%**，表面气压变化约 **-0.027%**。

**数值实现**：

```python
import mlx.core as mx

def diagnose_energy_gpu(u, v, T, ps, z, lat):
    """MLX GPU: 全球能量积分"""
    KE = 0.5 * (u**2 + v**2)
    IE = c_v * T
    PE = g * z
    total = KE + IE + PE
    
    weight = mx.cos(lat)[:, None] * mx.ones_like(total)
    energy = mx.sum(total * ps * weight) / g
    
    return energy
```

### 2.2 质量守恒诊断

大气干空气质量应严格守恒。表面气压的全球积分即为干空气质量：

\[
M_{\text{dry}} = \frac{1}{g}\int p_s \cos\phi \, d\phi \, d\lambda
\]

**验证标准**：在时间积分中，\( M_{\text{dry}} \) 的相对变化应小于 **10⁻⁶/天**。DCMIP-2012 干质量守恒测试中，FV3 和 MPAS 实现干质量精确守恒，GFS 在积分中增加了 0.05 hPa。

### 2.3 角动量守恒诊断

大气总角动量包括**相对角动量**和**行星角动量**：

\[
\text{Angular momentum} = a(U + \Omega a\cos^2\phi)
\]

其中 \( U \) 是纬向风，\( \Omega \) 是行星自转角速度。**验证标准**：在无地形、无摩擦的绝热积分中，总角动量应严格守恒。注意角动量守恒中忽略了与 \( \Omega a^2 \) 成正比的常数项，该项比其他两项大一个数量级。

### 2.4 位涡守恒诊断

在无摩擦、绝热条件下，**Ertel位涡**沿流体质点守恒：

\[
\text{PV} = \frac{1}{\rho}(\boldsymbol{\zeta} + 2\boldsymbol{\Omega}) \cdot \nabla\theta
\]

位涡不仅具有守恒性，还具有**可反演性**——在给定位涡分布和边界条件、并假定运动是平衡（如静力平衡、地转风平衡、热成风平衡）的情况下，可以反演出同一时刻的风、温度、位势高度等物理量的分布。

### 2.5 守恒律诊断的数值实现

```python
@njit(parallel=True, fastmath=True, cache=True)
def diagnose_conservation_laws(u, v, T, ps, z, lat, lon):
    """Numba JIT: 并行计算守恒律诊断"""
    nlat, nlon = u.shape
    
    # 能量积分
    KE = 0.5 * (u**2 + v**2)
    IE = c_v * T
    PE = g * z
    total_energy = 0.0
    for i in prange(nlat):
        weight = np.cos(lat[i])
        for j in range(nlon):
            total_energy += (KE[i,j] + IE[i,j] + PE[i,j]) * ps[i,j] * weight
    total_energy /= g
    
    # 质量积分
    dry_mass = np.sum(ps * np.cos(lat)[:, None]) / g
    
    # 角动量积分
    angular_momentum = np.sum((u + Omega * a * np.cos(lat)[:, None]**2) * 
                               np.cos(lat)[:, None])
    
    return total_energy, dry_mass, angular_momentum
```


## 三、第二层：动力学一致性检验

### 3.1 地转平衡检验

在自由大气中，风场应接近**地转风**：

\[
\mathbf{u}_g = \frac{1}{\rho f} \hat{\mathbf{k}} \times \nabla p
\]

**验证指标**：定义**地转偏差**：

\[
\text{AGD} = \frac{|\mathbf{u} - \mathbf{u}_g|}{|\mathbf{u}_g|}
\]

在中纬度自由大气中，AGD 应小于 **20%**。地转偏差是实际风与地转风之间的差异，其产生原因包括摩擦力、加速度和曲率效应。

### 3.2 热成风平衡检验

热成风关系是检验模型**垂直结构保真度**的核心工具：

\[
\frac{\partial \mathbf{u}_g}{\partial \ln p} = -\frac{R}{f} \hat{\mathbf{k}} \times \nabla T
\]

在模型中，热成风非平衡的动力部分会产生单斜且斜升力，出现低层向南、高层向北的水平非地转运动。

### 3.3 位涡可反演性检验

位涡的可反演性要求：给定**平衡条件**（静力平衡、地转风平衡、热成风平衡）下，从位涡分布可以反演出风、温度、位势高度场。

### 3.4 动能谱检验

大气能量应从**大尺度向小尺度级联**。**动能谱**应遵循：

\[
E(k) \propto \begin{cases}
k^{-3} & \text{大尺度（Enstrophy 级联）} \\
k^{-5/3} & \text{小尺度（能量级联）}
\end{cases}
\]

**验证方法**：计算模型输出的动能谱，与理论斜率对比。谱斜率的偏差反映数值耗散和参数化的质量。

### 3.5 网格印记检验

**网格印记**（Grid Imprinting）是数值方案在网格特定位置产生的虚假信号。DCMIP-2012 测试中专门评估了立方球面网格的立方体角点和二十面体网格的五边形处的截断误差信号。**验证标准**：网格印记的幅度应远小于物理信号。


## 四、第三层：辐射-能量一致性

### 4.1 行星能量平衡

全球年平均吸收短波辐射应等于向外长波辐射：

\[
\frac{S_0}{4}(1 - \alpha_p) = \text{OLR}
\]

其中 \( \alpha_p \) 是行星反照率。**验证标准**：偏差应小于 **1%**。

### 4.2 辐射-对流平衡

在对流层中，**湿绝热递减率** \( \Gamma_m \approx 6.5 \, \text{K/km} \) 应与辐射冷却平衡。检验方法：计算模型输出的温度递减率，与理论值对比。

### 4.3 能量收支的纬度分布

净辐射（吸收短波 - OLR）的纬度分布应满足：**赤道为正（能量盈余），极地为负（能量亏损）**，且经向热输运应补偿这个差异。

### 4.4 辐射加热率的垂直结构

短波加热率在云层中最大（云滴吸收），在晴空大气中主要由水汽、臭氧和 CO₂ 的吸收贡献。长波冷却在云顶最强，在近地层最弱。**验证标准**：加热率的垂直廓线应与理论一致。


## 五、第四层：水循环一致性

### 5.1 全球水量守恒

**全球蒸发应等于全球降水**：

\[
\int E \, dA = \int P \, dA
\]

**验证标准**：在长时间平均中，全球蒸发-降水差应小于 **1%**。

### 5.2 水文一致性检验框架

**HyCoT**（Hydrological Coherence Test）是一个用于评估网格化气候数据集与水文观测数据水文一致性的框架。对于虚拟世界生成器，可以借鉴其核心思想：

**径流-降水-蒸发一致性**：

\[
P = E + R + \Delta S
\]

其中 \( R \) 是径流，\( \Delta S \) 是储水量变化。在年尺度上，\( \Delta S \approx 0 \)，因此 \( P \approx E + R \)。

### 5.3 水汽收支检验

垂直积分的水汽收支为：

\[
\frac{\partial W}{\partial t} + \nabla \cdot \mathbf{Q} = E - P
\]

其中 \( W = \int_0^{\infty} \rho q \, dz \) 是可降水量，\( \mathbf{Q} = \int_0^{\infty} \rho q \mathbf{u} \, dz \) 是水汽通量。**验证标准**：在稳态下，\( P = E - \nabla \cdot \mathbf{Q} \)。

### 5.4 降水与环流的一致性

| 检验项 | 物理关系 | 可接受偏差 |
|--------|---------|-----------|
| ITCZ 降水 | 赤道辐合带上升气流 | 降水峰值纬度与 ITCZ 纬度差 < 5° |
| 副热带干燥 | 哈得来环流下沉支 | 降水最少区域与副热带高压带重合 |
| 副极地降水 | 气旋活动频繁 | 降水峰值纬度与副极地低压带差 < 5° |


## 六、第五层：海洋环流一致性

### 6.1 Sverdrup 平衡检验

在海洋内部，**Sverdrup 平衡**要求经向海流由风应力旋度驱动：

\[
\beta v = \frac{1}{\rho_0 H} \hat{\mathbf{k}} \cdot (\nabla \times \boldsymbol{\tau})
\]

卫星观测和 ARGO 浮标速度测量表明，Sverdrup 平衡在副热带环流内部是有效的。**验证标准**：在环流内部区域，Sverdrup 平衡的符合度应 > 70%。

**注意事项**：Sverdrup 平衡在以下区域可能失效：
- 北巴西流回旋区（相对涡度平流重要）
- 黑潮回流区（黑潮再循环的存在）
- 深层垂直速度扰动区域

### 6.2 Ekman 抽吸检验

正风应力旋度应驱动上升流，负旋度驱动下沉流：

\[
w_E = \frac{1}{\rho_0} \hat{\mathbf{k}} \cdot \nabla \times \left(\frac{\boldsymbol{\tau}}{f}\right)
\]

**验证标准**：赤道和副极地应有上升流（\( w_E > 0 \)），副热带应有下沉流（\( w_E < 0 \)）。

### 6.3 西边界流检验

西边界流（湾流、黑潮）应满足**Munk 边界层**的宽度尺度：

\[
\delta_M = (A_H/\beta)^{1/3}
\]

**验证标准**：西边界流的宽度应与 Munk 尺度一致，流速应远大于海洋内部。


## 七、第六层：生态一致性

### 7.1 Köppen 分类诊断

**Köppen-Geiger 分类**是评价气候模型保真度的标准诊断工具。将模型输出的月温度和月降水输入 Köppen 分类算法，得到气候类型图，与真实地球的 Köppen 图对比。

**验证基准**：历史 Köppen-Geiger 气候图的全球总体分类精度估计为 **82.39%**，其中南美洲最低（68.58%），大洋洲最高（92.01%）。全球平均精度为 **73.33%**。这些数值可作为虚拟世界生成器的参考基准。

**评估方法**：使用 GHCN-D 和 GSOD 站点观测数据作为参考。GHCN-D 数据集提供了全球陆地超过 **80,000** 个气象站的日气候数据，其中约三分之一同时具有温度和降水数据。

### 7.2 生物群系一致性

| 生物群系 | 温度约束 | 降水约束 | 验证方法 |
|---------|---------|---------|---------|
| 热带雨林 | \( T_{\text{cold}} > 18°\text{C} \) | \( P > 2000 \, \text{mm} \) | 与 ITCZ 位置对比 |
| 沙漠 | \( \text{PET} > 2P \) | \( P < 250 \, \text{mm} \) | 与副热带高压带对比 |
| 北方针叶林 | \( \text{MAT} < 8°\text{C} \) | \( P > 300 \, \text{mm} \) | 与极地冷空气范围对比 |
| 苔原 | \( T_{\text{hot}} < 10°\text{C} \) | \( P > 100 \, \text{mm} \) | 与极地辐射对比 |

### 7.3 土壤-气候一致性

| 土壤类型 | 气候条件 | 验证方法 |
|---------|---------|---------|
| 砖红壤 | \( \text{MAT} > 22°\text{C} \)，\( P > 1500 \, \text{mm} \) | 与热带雨林分布对比 |

| 游牧不在雨林 | 降水量 > 1500 mm 时，游牧适宜性应 < 0.2 | 逻辑一致 |

### 7.5 多尺度一致性

生物群系、土壤、农业类型在同一网格点上应**逻辑一致**：

```python
def check_multi_scale_consistency(biome, soil, agriculture):
    """检验多尺度一致性"""
    violations = []
    
    # 沙漠不应有冲积土和水稻
    mask_desert = (biome == DESERT)
    violations.append(np.sum(mask_desert & (soil == FLUVISOLS)))
    violations.append(np.sum(mask_desert & (agriculture == RICE)))
    
    # 热带雨林不应有永冻土
    mask_rainforest = (biome == TROPICAL_RAINFOREST)
    violations.append(np.sum(mask_rainforest & (soil == CRYOSOLS)))
    
    # 苔原不应有砖红壤
    mask_tundra = (biome == TUNDRA)
    violations.append(np.sum(mask_tundra & (soil == FERRALSOLS)))
    
    return violations
```


## 八、第七层：基准测试

### 8.1 Held-Suarez 测试

**Held-Suarez 测试**是大气动力学核心的标准基准。它用**牛顿松弛**替代完整物理参数化，产生一个理想化的“干大气”气候。**验证标准**：模型输出的**纬向平均温度**和**纬向风**应与参考解一致，偏差小于 **10%**。

### 8.2 Aquaplanet 测试

**Aquaplanet 测试**用**均匀水覆盖**的行星替代真实海陆分布，检验模型对**海气耦合**的模拟能力。实验设置基本遵循 Neale 和 Hoskins 提出的 Aquaplanet 实验（APE），但嵌入了简单的混合层海洋以实现海气耦合和表面温度预测。

**关键发现**：在多个 AGCM 的计算中，这种理想化产生了非常强的纬向平均流和夸大的 ITCZ 强度，但模型模拟仍然足够真实，可以用于隔离模型之间的关键差异。

### 8.3 湿润 Held-Suarez 测试（MITC）

**MITC** 是 Held-Suarez 测试的湿润变体，专门用于大气模型动力核心的比对。它基于 Held-Suarez 测试，但增加了湿物理过程。

### 8.4 JCM 验证框架

**JCM**（JAX Circulation Model）是一个可微分的中间复杂度大气模型，使用 JAX 数值库构建。其验证方法值得借鉴：

- 与原始 Fortran SPEEDY 代码在 T31 分辨率下进行验证
- 评估预测状态以及云量和降水等参数化量的全球气候态
- 两个模拟从等温静止开始运行三年，由 ERA-Interim 月气候态海表温度强迫

### 10.3 Numba JIT 加速

对于**逐网格的动力学一致性检验**（如地转偏差），用 Numba 编译：

```python
@njit(parallel=True, fastmath=True, cache=True)
def diagnose_geostrophic_deviation(u, v, p, lat, lon, R, Omega):
    """并行计算地转偏差"""
    nlat, nlon = u.shape
    agd = np.zeros((nlat, nlon))
    
    for i in prange(nlat):
        f = 2 * Omega * np.sin(lat[i])
        if abs(f) < 1e-6:
            continue  # 赤道附近跳过
        for j in range(nlon):
            dp_dlon = (p[i, (j+1)%nlon] - p[i, (j-1)%nlon]) / (2 * R * np.cos(lat[i]))
            dp_dlat = (p[min(i+1,nlat-1), j] - p[max(i-1,0), j]) / (2 * R)
            
            ug = -dp_dlat / (rho * f)
            vg = dp_dlon / (rho * f)
            
            speed = np.sqrt(u[i,j]**2 + v[i,j]**2) + 1e-6
            agd[i,j] = np.sqrt((u[i,j]-ug)**2 + (v[i,j]-vg)**2) / speed
    
    return agd
```
